```{admonition} Project: Test-rig report for the electric motor (✩✩)
:class: tip
On the test rig, the rotational speed of the motor was increased in twelve
steps from 250 to 3000 1/min. At each step, the torque at the shaft and the
electrical power input were measured. The measured values are already stored
as arrays in the first code cell. From them we create the figures and key
figures for the test-rig report.
```

```{admonition} Part 1: Read in the measurement data and compute characteristic quantities
:class: tip
In the code cell, the measured values are already stored as arrays `rpm`,
`torque` and `power_input`.

1. Check with `.shape` that all three arrays are the same length.
2. Compute the angular velocity `omega = 2 * np.pi * rpm / 60` in rad/s.
3. Compute the mechanical power `p_mech = torque * omega` in watts.
4. Compute the efficiency `efficiency = p_mech / power_input` and print the
   array.
```

```{code-cell} python
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
style.use('seaborn-v0_8')

rpm = np.array([250, 500, 750, 1000, 1250, 1500,
                1750, 2000, 2250, 2500, 2750, 3000])           # 1/min
torque = np.array([7.4, 6.7, 6.1, 5.4, 4.7, 4.1,
                   3.4, 2.9, 2.3, 1.7, 1.1, 0.5])              # Nm
power_input = np.array([1350, 1660, 1720, 1520, 1230, 980,
                        800, 720, 660, 600, 560, 470])         # W

# Add: check shapes, compute omega, p_mech and efficiency
```

````{admonition} Solution Part 1
:class: tip
:class: dropdown
```python
print(rpm.shape, torque.shape, power_input.shape)

omega = 2 * np.pi * rpm / 60
p_mech = torque * omega
efficiency = p_mech / power_input

print(efficiency)
```
All three arrays have the shape `(12,)`. The three calculations are vector
operations and act on the whole array. The efficiency lies between about 0.14
and 0.84 and is thus everywhere smaller than 1, as it must be for a real
motor. It first rises with the rotational speed, reaches a maximum and then
falls again.
````

````{admonition} Solution Part 3
```
The mechanical power is largest at about 644 W at 1500 1/min, the efficiency
at 0.84 only at 2000 1/min. The motor therefore does not deliver its highest
power at the rotational speed at which it has the lowest losses.
````

````{admonition} Solution Part 4
:class: tip
:class: dropdown
```python
efficiency_std = np.array([0.015, 0.018, 0.020, 0.022, 0.025, 0.024,
                           0.022, 0.020, 0.019, 0.018, 0.028, 0.030])

i_best = np.argmax(efficiency)

fig, ax = plt.subplots(figsize=(7, 4))

ax.errorbar(rpm, efficiency, yerr=efficiency_std,
            fmt='o', capsize=4, label='Measurement')
ax.scatter(rpm[i_best], efficiency[i_best],
           marker='*', s=200, color='red', zorder=5, label='Best operating point')

ax.set_xlabel('Rotational speed in 1/min')
ax.set_ylabel('Efficiency')
ax.set_title('Efficiency with measurement uncertainty')
ax.legend()
ax.grid(True)

plt.show()
```
The error bars are largest relative to the measured value at low rotational
speed, because the efficiency itself is small there. The best operating point
at 2000 1/min, on the other hand, is determined very precisely. The
`zorder=5` ensures that the star lies above the error bars.
````

```{admonition} Closing question
:class: tip
Answer in your own words, without further code:

1. The motor delivers its largest mechanical power at 1500 1/min, but works
   most efficiently at 2000 1/min. For which rotational speed would you design
   the motor for continuous operation? Justify.
2. At which measured points is the relative measurement uncertainty of the
   efficiency largest? What follows from this for planning further
   measurements?
```

````{admonition} Solution closing question
:class: tip
:class: dropdown
1. For continuous operation, one usually chooses a rotational speed close to
   the best efficiency, that is, about 2000 1/min. There, the least energy is
   lost as heat, the motor runs cooler and the operating costs are lower. The
   maximum power at 1500 1/min is more of interest for short-term load peaks.
   If the application permanently needs the highest power, the lower
   efficiency must be deliberately accepted.
2. The relative uncertainty is the quotient of `efficiency_std` and
   `efficiency`. It is largest at the low rotational speeds, because the
   efficiency itself is small there, while the absolute scatter stays
   similar. At 250 1/min it is over ten per cent. For further measurements it
   is worth taking more repeats in the lower rotational-speed range or using
   a more accurate measurement method. The well-measured range around
   2000 1/min, on the other hand, needs less effort.
````

````{admonition} Solution bonus exercise
:class: tip
:class: dropdown
```python
power_input_warm = np.array([1420, 1780, 1880, 1680, 1370, 1100,
                             910, 830, 770, 710, 660, 560])

efficiency_warm = p_mech / power_input_warm

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(rpm, efficiency,      marker='o', label='Cold motor')
ax.plot(rpm, efficiency_warm, marker='o', label='Warm motor')
ax.set_xlabel('Rotational speed in 1/min')
ax.set_ylabel('Efficiency')
ax.set_title('Efficiency with a cold and a warm motor')
ax.set_ylim(0, 1)
ax.legend()
ax.grid(True)
plt.show()

print(f"Peak efficiency cold: {np.max(efficiency):.2f} "
      f"at {rpm[np.argmax(efficiency)]} 1/min")
print(f"Peak efficiency warm: {np.max(efficiency_warm):.2f} "
      f"at {rpm[np.argmax(efficiency_warm)]} 1/min")
```
The peak efficiency drops from about 0.84 to about 0.73, that is, by more than
ten percentage points. The rotational speed of the best operating point
stays at 2000 1/min. The motor temperature therefore noticeably worsens the
efficiency without shifting the location of the optimum. For a reliable
report, the operating temperature at which the measurement was taken should
always be stated.
````
