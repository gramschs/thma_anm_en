# 8.2 Cooling Constant from Measured Data

In Chapter 8.1, business studies handed us the cost function ready-made. Now
you set up a cost function yourself. It measures how well a model fits
measured data, and gradient descent searches for the parameter for which the
model and the measurements agree best. Work through the parts in pairs if
possible, and in order.

````{admonition} Project: When can the part be packed? (✩✩)
:class: tip
A company washes aluminum parts and then dries them in an oven at
$100\,°\text{C}$. Afterwards, the parts cool down on a conveyor belt with a
fan in the factory, where the temperature is $20\,°\text{C}$. They may only be
wrapped in film below $40\,°\text{C}$, otherwise condensation forms inside the
packaging. A thermocouple measured the temperature of one part every
$5\,\text{s}$.

For the temperature $T$ at the time $t$, we use **Newton's law of cooling**:

$$T(t) = T_\infty + (T_0 - T_\infty) \cdot e^{-\lambda t}.$$

| Symbol | Meaning | Value |
| --- | --- | --- |
| $T_0$ | temperature when leaving the oven | $100\,°\text{C}$ |
| $T_\infty$ | temperature in the factory | $20\,°\text{C}$ |
| $\lambda$ | **cooling constant**, depends on shape, material and air flow | unknown, in $1/\text{s}$ |
| limit | highest temperature for packing | $40\,°\text{C}$ |

We are looking for the cooling constant $\lambda$ and the time the part has to
stay on the belt.
````

```{code-cell} python
import numpy as np
import matplotlib.pyplot as plt

# functions from Chapter 8.1
def central(function, point, dx):
    """Central difference quotient of function at the given point."""
    return (function(point + dx) - function(point - dx)) / (2 * dx)

def gradient_descent(function, start, learning_rate, tolerance,
                     max_iterations):
    """Search for a minimum of function, starting at start.

    Returns all visited points as an array.
    """
    point = start
    history = [point]
    for k in range(max_iterations):
        slope = central(function, point, 1e-6)
        # stopping criterion: slope almost zero
        if abs(slope) < tolerance:
            break
        point = point - learning_rate * slope
        history.append(point)
    return np.array(history)

# known temperatures in °C
T_start = 100.0
T_ambient = 20.0

# measurement times in s and measured temperatures in °C
t_meas = np.array([0, 5, 10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60])
T_meas = np.array([100.0, 82.6, 68.2, 56.9, 49.0, 41.9, 37.9, 35.2, 30.3,
                   27.8, 27.1, 25.5, 24.1])
```

````{admonition} Solution Part 1
:class: tip
:class: dropdown
```python
def model(t, lam):
    """Temperature in °C at the time t according to the law of cooling."""
    return T_ambient + (T_start - T_ambient) * np.exp(-lam * t)

# 200 times for smooth model curves
t_fine = np.linspace(0, 60, 200)

fig, ax = plt.subplots(figsize=(7, 4))
ax.scatter(t_meas, T_meas, color='black', label='measured values')
for lam in [0.03, 0.08]:
    ax.plot(t_fine, model(t_fine, lam), label=f'model with λ = {lam} 1/s')
ax.set_xlabel('Time in s')
ax.set_ylabel('Temperature in °C')
ax.set_title('Cooling of an aluminum part')
ax.legend()
ax.grid(True)
plt.show()
```
With $\lambda = 0.03\,\text{1/s}$, the model curve lies above the measured
values, so the model cools down too slowly. With $\lambda = 0.08\,\text{1/s}$,
it lies below them, so the model cools down too quickly. The larger
$\lambda$, the faster the temperature approaches the temperature in the
factory. So the $\lambda$ we are looking for lies between the two estimates,
by eye at about $0.05\,\text{1/s}$.
````

````{admonition} Part 2: Cost function from the measured data
:class: tip
We measure how well a value of $\lambda$ fits by the deviations between the
measured values and the model. We square each deviation and take the mean over
all $n$ measurements. This gives the **mean squared error** (MSE):

$$C(\lambda) = \frac{1}{n} \sum_{i=1}^{n} \bigl(T_{\text{meas},i} - T(t_i)\bigr)^2.$$

Because we square the deviations, positive and negative deviations do not
cancel each other out, and large deviations count more than small ones.
````

```{admonition} Closing question
:class: tip
1. The conveyor belt moves at $0.05\,\text{m/s}$. How long does the cooling
   section have to be at least?
2. The smallest value of the cost function is not zero, but
   $C = 0.36\,°\text{C}^2$. Why does gradient descent not find a $\lambda$ for
   which $C$ becomes zero? What does the square root of this value tell us
   about the fit?
```

````{admonition} Solution closing question
:class: tip
:class: dropdown
1. In $27.5\,\text{s}$ at $0.05\,\text{m/s}$, the part travels
   $0.05\,\text{m/s} \cdot 27.5\,\text{s} \approx 1.38\,\text{m}$. With some
   margin, the cooling section should therefore be at least $1.5\,\text{m}$
   long.
2. $C$ would only be zero if the model curve passed exactly through all 13
   measurement points. There are two reasons why it does not. First, the
   thermocouple does not measure exactly, and each measured value fluctuates a
   little up or down because of measurement noise. Second, the law of cooling
   is a simplification. For example, it assumes that the part has the same
   temperature everywhere and that the fan cools it uniformly. A smooth curve
   with a single free parameter can follow neither the noise nor every detail
   of the real cooling process.

   The square root of the mean squared error has the unit $°\text{C}$ again.
   Here it is $\sqrt{0.36\,°\text{C}^2} = 0.6\,°\text{C}$. So a measured value
   typically lies about $0.6\,°\text{C}$ away from the model curve. This is
   accurate enough for designing the cooling section. The value alone does not
   tell us how much of it is measurement noise and how much is model error.
   Only the deviations of the individual measured values from the curve show
   that. If they scatter up and down without a pattern, the noise dominates.
   If they stay on the same side over longer stretches, the model does not
   describe the process accurately.
````

````{admonition} Solution bonus exercise
:class: tip
:class: dropdown
1. The cost function is the same as in Part 2, only with `T_faulty`:

   ```python
   # task 1: lambda from the faulty measurement series
   T_faulty = T_meas.copy()
   T_faulty[6] = T_faulty[6] + 10

   def cost_faulty(lam):
       """Mean squared error for the faulty measurement series."""
       deviation = T_faulty - model(t_meas, lam)
       return np.mean(deviation**2)

   history = gradient_descent(cost_faulty, 0.03, 2e-6, 1e-3, 100)
   lam_faulty = history[-1]
   print(f'λ with outlier: {lam_faulty:.4f} 1/s')
   ```

   With the outlier, we get $\lambda = 0.0482\,\text{1/s}$ instead of
   $0.0504\,\text{1/s}$.
2. We compute the residuals with the $\lambda$ from task 1:

   ```python
   # task 2: residuals against time
   residuals = T_faulty - model(t_meas, lam_faulty)
   print('Residuals in °C:', np.round(residuals, 1))

   fig, ax = plt.subplots(figsize=(7, 4))
   ax.plot(t_meas, residuals, marker='o', linestyle='none')
   ax.axhline(0, color='gray')
   ax.set_xlabel('Time in s')
   ax.set_ylabel('Residual in °C')
   ax.set_title('Residuals with outlier')
   ax.grid(True)
   plt.show()
   ```

   Output:

   ```text
   Residuals in °C: [ 0.  -0.3 -1.2 -1.9 -1.5 -2.1  9.1  0.4 -1.3 -1.3 -0.1 -0.1 -0.3]
   ```

   At $9.1\,°\text{C}$, the residual at $30\,\text{s}$ is more than four times
   as large as all the others. It is also striking that the residuals from
   $10\,\text{s}$ to $25\,\text{s}$ are all negative. The outlier pulls the
   model curve upward, so near the outlier the curve lies above the correct
   measured values. Because the deviations are squared, a single large error
   carries a lot of weight.
3. We remove the entry with index 6 from both arrays:

   ```python
   # task 3: remove the outlier and determine lambda again
   t_clean = np.delete(t_meas, 6)
   T_clean = np.delete(T_faulty, 6)

   def cost_clean(lam):
       """Mean squared error without the outlier."""
       deviation = T_clean - model(t_clean, lam)
       return np.mean(deviation**2)

   history = gradient_descent(cost_clean, 0.03, 2e-6, 1e-3, 100)
   lam_clean = history[-1]

   # time until 40 °C with and without the outlier
   ratio = (T_start - T_ambient) / (40 - T_ambient)
   t_40_faulty = np.log(ratio) / lam_faulty
   t_40_clean = np.log(ratio) / lam_clean
   print(f'λ without outlier: {lam_clean:.4f} 1/s')
   print(f'Time until 40 °C with outlier:    {t_40_faulty:.1f} s')
   print(f'Time until 40 °C without outlier: {t_40_clean:.1f} s')
   ```

   Output:

   ```text
   λ without outlier: 0.0504 1/s
   Time until 40 °C with outlier:    28.8 s
   Time until 40 °C without outlier: 27.5 s
   ```

   Without the outlier, we again find $\lambda = 0.0504\,\text{1/s}$ and
   $27.5\,\text{s}$ until $40\,°\text{C}$. A single wrong measured value
   increased the waiting time by a little over one second. Here the error is
   harmless, because it leads to a longer cooling section. If the measured
   value had been $10\,°\text{C}$ too low, we would have underestimated the
   waiting time. That is why looking at the residuals is part of every fit of
   a model to measured data.
````
