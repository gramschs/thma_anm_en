
````{admonition} Solution
:class: tip
:class: dropdown
```python
print(type(120))
print(type(27.8))
print(type('test_car_3'))
print(type(120 / 4))
print(type(2 ** 8))
print(type(27.8 > 33.3))
```
`120` is an integer, `27.8` a float and `'test_car_3'` a string. `120 / 4`
always yields a float with the `/` operator, even if the result is a whole
number. `2 ** 8` stays an integer, because both operands are integers. The
comparison `27.8 > 33.3` yields the data type `bool`, because comparisons
always return a truth value.
````


````{admonition} Solution
:class: tip
:class: dropdown
```python
speed_ms = 30.0
speed_limit_ms = 33.3

if speed_ms > speed_limit_ms:
    print('too fast')
elif speed_ms == speed_limit_ms:
    print('exactly at the limit')
else:
    print('within the limit')
```
With `speed_ms = 30.0` the first condition is false and the second one too,
so the `else` branch takes effect and the output is `within the limit`. With
`speed_ms = 33.3` the first condition is still false, but the second one
(`==`) is true, so the output is then `exactly at the limit`.
````

````{admonition} Solution
:class: tip
:class: dropdown
```python
speed_limit_ms = 33.3

for time_step in range(7):
    speed_ms = time_step * 7.0
    print(f'Time step {time_step}: {speed_ms:.1f} m/s')
    if speed_ms > speed_limit_ms:

The first gap is `7.0` (increase per time step), the second one the condition
`speed_ms > speed_limit_ms`. The speed takes the values 0, 7, 14, 21, 28, 35
and 42 m/s. `too fast` appears in time steps 5 and 6.
````

```{admonition} Exercise E (✩✩✩, mini-project)
:class: tip
A test rig simulates an acceleration test over ten time steps. Implement the
following steps.

**Part 1:** Write a for loop with `range(10)` for the time steps 0 to 9. In
each time step the speed is `speed_ms = time_step * 5.0`. Print the time step
and speed with an f-string.

**Part 2:** Add an `if`/`else` check in the loop body that prints for each
time step whether the speed limit `speed_limit_ms = 33.3` is observed or
exceeded.

**Part 3:** Count in how many time steps the speed limit is exceeded. For
this, create a variable `count_too_fast = 0` before the loop and increase it
by 1 in the appropriate case. Print the number after the loop.

**Closing question:** From which time step onwards is the speed limit
exceeded, and how does that relate to the chosen acceleration of 5.0 m/s per
time step?
```

```{code-cell} python
# code cell
```

````{admonition} Solution
:class: tip
:class: dropdown
```python
speed_limit_ms = 33.3
count_too_fast = 0

for time_step in range(10):
    speed_ms = time_step * 5.0
    if speed_ms > speed_limit_ms:
        print(f'Time step {time_step}: {speed_ms:.1f} m/s, too fast')
        count_too_fast = count_too_fast + 1
    else:
        print(f'Time step {time_step}: {speed_ms:.1f} m/s, within the limit')

print(f'Too fast in {count_too_fast} time steps.')
```
The speed takes the values 0, 5, 10, ... up to 45 m/s. The speed limit is
exceeded from `time_step = 7` onwards, because there the speed is
`7 * 5.0 = 35.0` m/s and is above 33.3 m/s for the first time. In total the
vehicle is too fast in time steps 7, 8 and 9, that is, in three time steps.
The variable `count_too_fast` acts as a counter that we increase by 1 in each
matching pass. With a larger acceleration per time step, the limit would be
exceeded earlier.
````
