6.3 Driving Along a Path

In Chapter 6.2 the AGV stopped in front of a box. The fleet manager, i.e. the computer that coordinates all vehicles in the warehouse, now sends it a detour path: a sequence of points that leads between the box and the pillar to the transfer station. The path points tell the AGV where to go, but not which way it has to point along the way. How do we determine the yaw angle from the path points?

So far, the pose was always given. Now we compute the yaw angle from the path and check in the figure whether the AGV gets past the box and the pillar.

Learning objectives¶

Learning objectives

  • You can compute the yaw angle of a direction of travel with np.arctan2 and explain why np.arctan is not enough for this.

  • You can determine the yaw angle for every point of a path and know that the direction to the next path point only approximates the direction of the path.

  • You can build the transformation matrix TWV\mathbf{T}_{WV}TWV​ for every path point and plot the outline of the vehicle along the path.

In which direction does the AGV have to drive?¶

The detour path consists of nine path points from the vehicle center at (4,2)(4, 2)(4,2) to the transfer station at (8,2.5)(8, 2.5)(8,2.5). At each path point, the AGV should point toward the next path point.

First we run two cells: the plotting function from Chapter 6.1, whose parameter path draws path points as a dashed line, and a cell with the functions and data from Chapters 5.3 and 6.1. The warehouse map now also contains the box, and the path points are stored row by row in the array path.

import numpy as np
import matplotlib.pyplot as plt

# functions from Chapter 5.3
def transformation_matrix(angle, tx, ty):
    """Homogeneous matrix: rotate by angle (radians), then shift by (tx, ty)."""
    return np.array([
        [np.cos(angle), -np.sin(angle), tx],
        [np.sin(angle),  np.cos(angle), ty],
        [0.0,            0.0,           1.0],
    ])

def transform(T, points):
    """Applies the homogeneous matrix T to all points, row = [x, y]."""
    points_hom = np.ones((len(points), 3))
    points_hom[:, 0:2] = points
    result = (T @ points_hom.T).T
    return result[:, 0:2]

The direction to the next path point is the difference vector path[1] - path[0] with the components Δx\Delta xΔx and Δy\Delta yΔy. For its angle ψ\psiψ measured from the xWx_WxW​-axis, we have

tan⁡ψ=ΔyΔx.\tan\psi = \frac{\Delta y}{\Delta x}.tanψ=ΔxΔy​.

So the obvious choice is the arctangent np.arctan. np.rad2deg, the counterpart of np.deg2rad, converts its result from radians to degrees. We try it out for the first segment and for the later return trip to the start.

# direction from the first to the second path point
direction = path[1] - path[0]
psi_out = np.arctan(direction[1] / direction[0])
print('Direction vector to the next path point in m:', direction)
print(f'Yaw angle with np.arctan: {np.rad2deg(psi_out):.1f}°')

# return trip: from the last path point (station) back to the first (start)
direction_back = path[0] - path[-1]
psi_back = np.arctan(direction_back[1] / direction_back[0])
print('Direction vector for the return trip in m:', direction_back)
print(f'Yaw angle with np.arctan: {np.rad2deg(psi_back):.1f}°')

For the first segment, −29.2°-29.2°−29.2° matches the figure. The return trip, however, leads to the left, and 7.1°7.1°7.1° points to the right, directly away from the starting point. Why does the arctangent get it wrong?

Math refresher: arctangent and quadrants

The arctangent only returns angles between −90°-90°−90° and 90°90°90°. The directions (4,0.5)(4, 0.5)(4,0.5) and (−4,−0.5)(-4, -0.5)(−4,−0.5) have the same quotient 0.125 and cannot be told apart this way. For Δx=0\Delta x = 0Δx=0, the quotient is not even defined. The function arctan2 takes Δy\Delta yΔy and Δx\Delta xΔx separately, determines the quadrant from their signs and returns angles from −180°-180°−180° to 180°180°180°.

NumPy provides it as np.arctan2(dy, dx). As in the quotient, the yyy-component comes first.

# yaw angle with np.arctan2(dy, dx): first the y-component, then the x-component
psi_start = np.arctan2(direction[1], direction[0])
psi_back = np.arctan2(direction_back[1], direction_back[0])
print(f'Yaw angle to the next path point: {np.rad2deg(psi_start):.1f}°')
print(f'Yaw angle for the return trip: {np.rad2deg(psi_back):.1f}°')
Yaw angle to the next path point: -29.2°
Yaw angle for the return trip: -172.9°

For the first segment, nothing changes, because Δx>0\Delta x > 0Δx>0 there. For the return trip, np.arctan2 now returns −172.9°-172.9°−172.9°, exactly 180°180°180° less than the arctangent, i.e. the opposite direction.

How does the AGV turn along the path?¶

Now we repeat the calculation for all segments: at path point k, the AGV should point toward path point k + 1. Nine path points have eight segments, so the loop runs over range(len(path) - 1). As with the scan points in Chapter 6.1, we collect the yaw angles in an array that we create beforehand with np.zeros. The last path point has no successor and takes over the second-to-last angle.

# yaw angle at each path point: direction to the next path point
psi = np.zeros(len(path))
for k in range(len(path) - 1):
    direction = path[k + 1] - path[k]
    psi[k] = np.arctan2(direction[1], direction[0])

# the last path point has no successor and keeps the last direction
psi[-1] = psi[-2]

psi_deg = np.rad2deg(psi)
print('Yaw angles in degrees:', np.round(psi_deg, 1))

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(range(len(path)), psi_deg, marker='o')
ax.set_xlabel('Path point k')
ax.set_ylabel('Yaw angle in degrees')
ax.set_title('Yaw angle along the detour path')
ax.grid(True)
plt.show()
Yaw angles in degrees: [-29.2 -18.8  -9.1  -2.3  25.6  43.8  33.4   0.    0. ]

The AGV starts with −29.2°-29.2°−29.2° toward the lower right, first turns left, then right again, and stands at the station with 0°0°0°, parallel to the warehouse wall.

psi[k] is the direction of the secant, i.e. the line segment from path point k to path point k + 1. The direction of the path at the point itself, on the other hand, is given by the tangent. At the lowest path point k = 4, the path runs roughly horizontally, but the AGV already points upward at 25.6°25.6°25.6°. The slope Δy/Δx\Delta y / \Delta xΔy/Δx of the secant is called the difference quotient. In Chapter 7.1 we use it to approximate derivatives.

      f'from path point {k_right} to {k_right + 1}')

The loop fills only the entries psi[0] to psi[7], one per segment. The last entry psi[8] is set by the line psi[-1] = psi[-2] after the loop. Without this line, it would stay at the initial value 0 from np.zeros. For our path, that would happen to be correct, but not for a different path. The largest left turn is 27.9°27.9°27.9° from path point 3 to 4. There the AGV has reached the lowest point and heads back up. The largest right turn is −33.4°-33.4°−33.4° from path point 6 to 7, where the AGV straightens out parallel to the wall for the station. With twice as many path points, each of these turns is spread over more and smaller steps, each roughly half as large. The secants become shorter and match the tangent better. The AGV therefore drives more smoothly and points more precisely in the direction of the path at each path point.

The simple difference of two yaw angles works here because our path never leads in the negative xWx_WxW​-direction. There, np.arctan2 jumps from 180°180°180° to −180°-180°−180°, and the difference can be off by 360°360°360°. Exercise 6.4 in Chapter 6.5 shows how this happens and how we correct the value.

Does the AGV get past the box?¶

With path[k] and psi[k], we know the pose at every path point. As in Chapter 6.1, we use it to build TWV\mathbf{T}_{WV}TWV​ and convert the outline to warehouse coordinates, this time in a loop. As with the distances in Part 3 of Chapter 6.2, we collect the outlines in a list: before the loop, we create an empty list, and append adds each new outline to the end. The parameter limits shows only the section around the path.

# empty list for the outlines at all path points
vehicles = []
for k in range(len(path)):
    # pose at path point k: position from the path, yaw angle from psi
    T_WV_k = transformation_matrix(psi[k], path[k, 0], path[k, 1])
    # convert the outline to warehouse coordinates and append it to the list
    vehicles.append(transform(T_WV_k, outline))

Summary and outlook¶

We compute the yaw angle between two path points with np.arctan2(dy, dx). Unlike np.arctan, this function determines the quadrant from the signs and returns angles from −180°-180°−180° to 180°180°180°. In a loop, we get the yaw angle at every path point, approximated by the direction of the secant. With the position and the yaw angle, we build TWV\mathbf{T}_{WV}TWV​ at every path point and collect the outlines in a list.

In the project in Chapter 6.4, the AGV turns into an aisle on a quarter circle. We use the inverse matrix from Chapter 6.1 to calculate how close it comes to a rack corner. We will take a closer look at the difference quotient in Chapter 7.1.
