```{admonition} Exercise 1.1 (✩)
:class: tip
Which data type is present? Write your guess after the arrow before you run
the code.

* `7` -->
* `-7` -->
* `'steel'` -->
* `7.0` -->
* `7,0` -->
* `7**2` -->
* `7**(1/2)` -->
* `7 == 7.0` -->

Then check each line with `type()` in a code cell.
```

```{code-cell} python
# code cell
```

````{admonition} Solution
:class: tip
:class: dropdown
```python
print(type(7))
print(type(-7))
print(type('steel'))
print(type(7.0))

comma_number = 7,0
print(type(comma_number))

print(type(7**2))
print(type(7**(1/2)))
print(type(7 == 7.0))
```
`7` and `-7` are integers, `'steel'` is a string, `7.0` is a float. `7**2`
stays an integer (`49`), `7**(1/2)` is a float (`2.6457513110645907`).
`7 == 7.0` is a `bool` with the value `True`, because Python looks at the
numeric value in a comparison, not the data type.

The most interesting case is `7,0`: in Python the comma does not create a
decimal number but a **tuple** `(7, 0)`, so `type(comma_number)` returns
`tuple`. No error occurs in the process, which makes this typo particularly
treacherous. For decimal numbers, therefore, always use a point instead of a
comma.
````

```{admonition} Exercise 1.2 (✩✩)
:class: tip
```
````{admonition} Solution
:class: dropdown
```python

```
````

````{admonition} Solution
so the result is `False`. With `or` one true side is enough, so the result
is `True`.
````

```{code-cell} python
# code cell
```


```{admonition} Exercise 1.10 (✩✩)
:class: tip
Write a function `stress(force_n, cross_section_mm2=100)` that computes and
returns the mechanical stress `sigma = force_n / cross_section_mm2` in N/mm²
(MPa). Give the function a docstring. Call the function once with
`force_n = 5000` and the default cross section, and once with `force_n = 5000`
and `cross_section_mm2 = 50`. Compare the two results in one sentence.
```

```{code-cell} python
# code cell
```

````{admonition} Solution
:class: tip
:class: dropdown
```python
def stress(force_n, cross_section_mm2=100):
    """Computes the mechanical stress in MPa (N/mm²)."""
    return force_n / cross_section_mm2

print(f'{stress(5000):.1f} MPa')
print(f'{stress(5000, cross_section_mm2=50):.1f} MPa')
```
With the default cross section of 100 mm² the stress is 50.0 MPa, with the
smaller cross section of 50 mm² the stress doubles to 100.0 MPa. The same
force is distributed over less area with a smaller cross section, which
increases the stress.
````

```{admonition} Exercise 1.11 (✩✩✩, mini-project)
:class: tip
In a tensile test, a sample with the constant cross section
`cross_section_mm2 = 19.6` is loaded step by step. The measured forces are
`forces_n = [1200, 3400, 5800, 7200, 8100, 6500]`. Implement the following
steps.

**Part 1:** Write a function `stress(force_n, cross_section_mm2)` that returns
the stress in MPa.

**Part 2:** Create a dictionary `test` with the keys `material` (`'S235JR'`),
`cross_section_mm2` (19.6) and `yield_strength_mpa` (235.0).

**Part 3:** Iterate over `forces_n` with a for loop. Compute the stress for
each value with your function and print for each measured value whether the
yield strength from the dictionary is exceeded (`'In the elastic range'` or
`'Yield strength exceeded'`). Also keep track of the force at which the yield
strength is first exceeded.

**Part 4:** Determine the maximum stress of the entire measurement series
without `max()` and print it at the end.

**Closing question:** At which force from the list is the yield strength first
exceeded, and what does that mean physically for the material sample?
```

```{code-cell} python
# code cell
```

````{admonition} Solution
:class: tip
:class: dropdown
```python
def stress(force_n, cross_section_mm2):
    """Computes the mechanical stress in MPa (N/mm²)."""
    return force_n / cross_section_mm2

test = {
    'material': 'S235JR',
    'cross_section_mm2': 19.6,
    'yield_strength_mpa': 235.0
}

forces_n = [1200, 3400, 5800, 7200, 8100, 6500]

max_stress = 0
first_exceedance_force = 0
exceedance_found = False

for force in forces_n:
    sigma = stress(force, test['cross_section_mm2'])

    if sigma > test['yield_strength_mpa']:
        status = 'Yield strength exceeded'
        if not exceedance_found:
            first_exceedance_force = force
            exceedance_found = True
    else:
        status = 'In the elastic range'

    print(f'{force} N -> {sigma:.1f} MPa: {status}')

    if sigma > max_stress:
        max_stress = sigma

print(f'Maximum stress: {max_stress:.1f} MPa')
print(f'First exceedance at {first_exceedance_force} N')
```
The yield strength of 235.0 MPa is first exceeded at 5800 N, where the stress
is about 295.9 MPa. The maximum stress of the entire measurement series
occurs at the largest force of 8100 N and is about 413.3 MPa, because with a
constant cross section the stress grows proportionally to the force.

Physically, exceeding the yield strength means that from this loading point
onwards the material sample no longer deforms purely elastically, but
plastically. The sample thus takes on a permanent deformation that does not
disappear even after complete unloading.
````
