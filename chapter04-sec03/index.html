4.3 Displacements and Forces in a Truss

In Chapter 4.1 we assembled the stiffness matrix of the swing set, and in Chapter 4.2 that of a wall bracket. Both times the matrix was singular, because the supports were still missing from the system of equations. In this chapter we add the supports and solve the system of equations. How far does the apex of the swing set sink under the load, and can the structure carry the load at all?

Learning objectives¶

Learning objectives

  • You can add supports to the system of equations by replacing the equations of the constrained degrees of freedom, and compute the displacements with np.linalg.solve.

  • You can compute the support reactions and the member forces from the displacements and distinguish tension from compression.

  • You can compare the stress in a member with the yield strength and know that compression members must also be checked for buckling.

Adding supports and solving the system of equations¶

import numpy as np
import matplotlib.pyplot as plt

# function from Chapter 4.1
def assemble_stiffness_matrix(node_pos, members, youngs_modulus, area):
    """Assembles the stiffness matrix of a plane truss.

    node_pos: node coordinates in m, row n = [x_n, y_n]
    members: member list, row s = [i, j]
    youngs_modulus: E in N/m², the same for all members
    area: A in m², the same for all members
    Returns: stiffness matrix K in N/m, shape (2 * number of nodes, 2 * number of nodes)
    """
    num_dofs = 2 * len(node_pos)
    K = np.zeros((num_dofs, num_dofs))

    for i, j in members:
        # geometry and stiffness of the member
        difference = node_pos[j] - node_pos[i]
        length = np.sqrt(difference[0]**2 + difference[1]**2)
        k = youngs_modulus * area / length
        e = difference / length

        # stiffness block of the member
        block = k * np.array([
            [e[0] * e[0], e[0] * e[1]],
            [e[1] * e[0], e[1] * e[1]],
        ])

        # add the block to K: +block at i-i and j-j, -block at i-j and j-i
        K[2*i : 2*i + 2, 2*i : 2*i + 2] += block
        K[2*j : 2*j + 2, 2*j : 2*j + 2] += block
        K[2*i : 2*i + 2, 2*j : 2*j + 2] -= block
        K[2*j : 2*j + 2, 2*i : 2*i + 2] -= block

    return K

The system of equations K⋅u⃗=F⃗\mathbf{K} \cdot \vec{u} = \vec{F}K⋅u=F has six equations, one for each degree of freedom. For the support nodes, however, we already know the displacement, namely zero. We therefore replace the equations of the constrained degrees of freedom with exactly this condition.

# make copies so that K and force_vector stay unchanged
K_supported = K.copy()
force_supported = force_vector.copy()

# replace the equations of the constrained degrees of freedom with u_d = 0
for n in support_indices:
    for d in [2 * n, 2 * n + 1]:
        K_supported[d, :] = 0.0     # set the whole row d to zero
        K_supported[d, d] = 1.0     # diagonal to one: 1 * u_d ...
        force_supported[d] = 0.0    # ... = 0

print('K_supported in kN/mm:')
print(np.round(K_supported * 1e-6, 2))
print('Row 0 of K_supported in N/m:', K_supported[0])
print(f'Determinant of K_supported: {np.linalg.det(K_supported):.4e}')

In K_supported, rows 0, 1, 4 and 5 are replaced. Each of these rows now contains only a one on the diagonal, and the right-hand side is zero. So the row simply says ud=0u_d = 0ud​=0. In the matrix printed in kN/mm, the ones appear as 0., because we multiply all entries by 10-6. The last output shows row 0 in N/m. The determinant is no longer zero, so the system is solvable. Because we only replaced rows, K_supported is no longer symmetric. For np.linalg.solve this does not matter.

The method .copy() is important. Without it, K_supported and K would refer to the same array, and we would overwrite the original stiffness matrix. But we still need it shortly for the support reactions.

u = np.linalg.solve(K_supported, force_supported)

print('Displacements in mm:')
for n in range(num_nodes):
    print(f'  Node {n}: ux = {u[2*n] * 1000:8.4f} mm,  uy = {u[2*n + 1] * 1000:8.4f} mm')

The apex sinks by 0.17 mm0.17\,\text{mm}0.17mm and does not move sideways. This is consistent with the symmetry: both members are identical and mirror images of each other, and the load points straight down. We can even check the value by hand. In Chapter 4.1 we saw that the block of node 1 has entries only on the diagonal. In the yyy-direction the apex has the stiffness 11.80 kN/mm11.80\,\text{kN/mm}11.80kN/mm. So uy=−2 kN/11.80 kN/mm=−0.17 mmu_y = -2\,\text{kN} / 11.80\,\text{kN/mm} = -0.17\,\text{mm}uy​=−2kN/11.80kN/mm=−0.17mm.

We need these steps again for every truss. We therefore combine them in a function.

def compute_displacements(K, force_vector, support_indices):
    """Solves K * u = F for a truss with pin supports.

    K: stiffness matrix in N/m
    force_vector: external node forces in N
    support_indices: list of supported nodes, where ux = uy = 0
    Returns: displacement vector u in m
    """
    K_supported = K.copy()
    force_supported = force_vector.copy()
    for n in support_indices:
        for d in [2 * n, 2 * n + 1]:
            K_supported[d, :] = 0.0
            K_supported[d, d] = 1.0
            force_supported[d] = 0.0
    return np.linalg.solve(K_supported, force_supported)

u = compute_displacements(K, force_vector, support_indices)
print('Displacement vector in mm:', np.round(u * 1000, 4))

Which forces act in the supports and in the members?¶

We now know the displacements. If we substitute them into the original equation F⃗=K⋅u⃗\vec{F} = \mathbf{K} \cdot \vec{u}F=K⋅u, we get the external forces at all nodes.

# node forces from the original stiffness matrix
node_forces = K @ u

print('Node forces in N:')
for n in range(num_nodes):
    print(f'  Node {n}: Fx = {node_forces[2*n]:8.1f} N,  Fy = {node_forces[2*n + 1]:8.1f} N')

print(f'Sum Fx: {np.sum(node_forces[0::2]):.1f} N')
print(f'Sum Fy: {np.sum(node_forces[1::2]):.1f} N')

At node 1 we get exactly the load we prescribed. That is our check. At the support nodes 0 and 2 we find the support reactions, i.e. the forces with which the supports hold the truss in place. Each support carries half of the load upward. In addition, the left support pushes to the right with 500 N500\,\text{N}500N and the right one to the left with 500 N500\,\text{N}500N. All forces together add up to zero, so the truss is in equilibrium like the beam in Chapter 3.2. The expression node_forces[0::2] selects every second entry starting at index 0, i.e. all xxx-forces.

For the design we want to know how heavily each individual member is loaded. The member force NNN follows directly from the spring equation of Chapter 4.1: N=k⋅ΔLN = k \cdot \Delta LN=k⋅ΔL. As in the figure on splitting the displacement from Chapter 4.1, the change in length ΔL\Delta LΔL is the component of the displacement in the direction of the member. This time, however, both ends of the member can move. What counts is therefore the displacement of node jjj relative to node iii, i.e. u⃗j−u⃗i\vec{u}_j - \vec{u}_iuj​−ui​.

def compute_member_forces(node_pos, members, youngs_modulus, area, u):
    """Computes the member forces of a truss from the displacements.

    node_pos: node coordinates in m, row n = [x_n, y_n]
    members: member list, row s = [i, j]
    youngs_modulus: E in N/m², the same for all members
    area: A in m², the same for all members
    u: displacement vector in m
    Returns: member forces in N, positive = tension, negative = compression
    """
    member_forces = np.zeros(len(members))
    for s in range(len(members)):
        i, j = members[s]
        # geometry and stiffness as in assemble_stiffness_matrix
        difference = node_pos[j] - node_pos[i]
        length = np.sqrt(difference[0]**2 + difference[1]**2)
        k = youngs_modulus * area / length
        e = difference / length

        # displacement of node j relative to node i
        u_relative = u[2*j : 2*j + 2] - u[2*i : 2*i + 2]

        # change in length = component along the member, member force N = k * delta_l
        delta_l = e[0] * u_relative[0] + e[1] * u_relative[1]
        member_forces[s] = k * delta_l
    return member_forces

member_forces = compute_member_forces(node_pos, members, youngs_modulus,
                                      area, u)

for s in range(len(members)):
    if abs(member_forces[s]) < 1e-6:   # below 1 µN: just a rounding error
        kind = 'zero force'
    elif member_forces[s] > 0:
        kind = 'tension'
    else:
        kind = 'compression'
    print(f'Member {s}: N = {member_forces[s]:8.1f} N  ({kind})')

Both members carry 1118 N1118\,\text{N}1118N in compression. A positive member force means tension: the member gets longer. A negative member force means compression: the member gets shorter. The result is plausible: the load pushes the apex down, the apex moves closer to the two supports, and both members are compressed. The member force is larger than half the load because the members are inclined. Each member has to carry 1000 N1000\,\text{N}1000N in the vertical direction. Of its force, however, only the fraction sin⁡φ=2/5≈0.894\sin\varphi = 2/\sqrt{5} \approx 0.894sinφ=2/5​≈0.894 points upward. The member force is therefore larger: 1000 N/0.894≈1118 N1000\,\text{N} / 0.894 \approx 1118\,\text{N}1000N/0.894≈1118N.

Will the swing set hold?¶

First we show the result graphically. At less than one millimeter, the displacements are much smaller than the members, which are over two meters long. So that we can see anything at all, we magnify the displacements in the plot by an exaggeration factor, here 2000. The calculation itself does not change.

plot_truss(node_pos, members, support_indices, force_vector=force_vector,
           displacement=u, scale=2000, member_forces=member_forces,
           title='Swing set, displacements exaggerated by a factor of 2000')

The dashed lines show the initial shape, the solid lines the exaggerated deformed shape. Both members are red, so they are in compression.

Can the steel withstand these forces? To find out, we compute the stress σ=N/A\sigma = N/Aσ=N/A and compare it with the yield strength. For structural steel S235 it is Re=235 N/mm2R_e = 235\,\text{N/mm}^2Re​=235N/mm2.

yield_strength = 235.0   # structural steel S235 in N/mm²

# stress sigma = N / A, converted from N/m² to N/mm²
stresses = member_forces / area * 1e-6

for s in range(len(members)):
    utilization = abs(stresses[s]) / yield_strength
    print(f'Member {s}: sigma = {stresses[s]:6.1f} N/mm²,  '
          f'utilization {utilization * 100:4.1f} %')

The stress is only about 14 N/mm214\,\text{N/mm}^214N/mm2, i.e. about 6 % of the yield strength. Is the swing set therefore safe? No, because for compression members the stress alone is not a sufficient check. A slender member under compression can deflect sideways: it buckles long before the steel starts to yield. From mechanics of materials we know the Euler buckling load for this. For a member that is pinned at both ends, it is

Fcr=π2 E IL2withI=π d464F_\text{cr} = \frac{\pi^2\,E\,I}{L^2} \qquad \text{with} \qquad I = \frac{\pi\,d^4}{64}Fcr​=L2π2EI​withI=64πd4​

for a circular cross-section.

# area moment of inertia of the circular cross-section in m^4
moment_of_inertia = np.pi * diameter**4 / 64

# Euler buckling load for member 0 (both members have the same length)
length = np.sqrt(1.0**2 + 2.0**2)   # Pythagorean theorem with dx = 1 m, dy = 2 m
buckling_load = np.pi**2 * youngs_modulus * moment_of_inertia / length**2

print(f'Euler buckling load:         {buckling_load:8.1f} N')
print(f'Compressive force in member: {abs(member_forces[0]):8.1f} N')

The buckling load is only about 203 N203\,\text{N}203N, and the compressive force is more than five times as large. The members with a diameter of 1 cm1\,\text{cm}1cm would therefore buckle, even though the stress is far below the yield strength. The design of a truss therefore always requires both checks: the stress for all members and buckling for all compression members.

Summary and outlook¶

We add the supports by replacing the equations of the constrained degrees of freedom with ud=0u_d = 0ud​=0. After that, the system of equations is solvable, and np.linalg.solve gives all displacements. Substituting them into K⋅u⃗\mathbf{K} \cdot \vec{u}K⋅u gives the support reactions at the supports. The member forces follow from the change in length of each member: positive means tension and negative means compression. For the design we compare the stress with the yield strength and also check all compression members for buckling.

All steps are now contained in three functions: assemble_stiffness_matrix, compute_displacements and compute_member_forces. In the next chapter, working in pairs, we use them to analyze and evaluate the roof truss of a steel building under snow load.
