7.2 How Small Can the Step Size Be?

In Chapter 7.1, the AGV started accelerating abruptly and stopped accelerating just as abruptly. The load feels such jumps in acceleration as a jolt. The rate of change of the acceleration, i.e. its derivative with respect to time, is called jerk. That is why the fleet manager plans a smoother start: the velocity rises from 0 to 0.8 m/s0.8\,\text{m/s}0.8m/s in 2 s2\,\text{s}2s without a kink. With ttt in seconds and sss in meters, the distance is

s(t)=0.4(t−2πsin⁡(πt2))for 0≤t≤2.s(t) = 0.4 \left(t - \frac{2}{\pi} \sin\left(\frac{\pi t}{2}\right)\right) \quad \text{for } 0 \le t \le 2.s(t)=0.4(t−π2​sin(2πt​))for 0≤t≤2.

Unlike with measured values, we can now evaluate sss at any point and choose the step size freely. There is no measurement noise either. In Chapter 7.1, the noise was the reason why a small step size was not always better. Without measurement noise, does the derivative get more and more accurate as the step size gets smaller?

Since we know the exact derivative, we can measure the error precisely. In Chapter 8, we use the step size that proves best here for functions whose derivative we do not want to work out as a formula.

Learning objectives¶

Learning objectives

  • You can write difference quotients as Python functions that take another function as an argument.

  • You can plot the error of a difference quotient against the step size on a log-log plot and read off the order of accuracy.

  • You can use the Taylor expansion to explain why the central difference quotient has order of accuracy 2 and the forward difference quotient has order of accuracy 1.

  • You know why step sizes that are too small do harm because of rounding errors, and you know a good step size for both difference quotients.

How accurate is the difference quotient?¶

First, we write the formula as a Python function motion_profile(t). For comparison, we also program its derivative, the exact velocity s′(t)=v(t)=0.4(1−cos⁡(πt2))s'(t) = v(t) = 0.4 \left(1 - \cos\left(\frac{\pi t}{2}\right)\right)s′(t)=v(t)=0.4(1−cos(2πt​)).

import numpy as np
import matplotlib.pyplot as plt

# model of the smooth start: distance and exact velocity
def motion_profile(t):
    """Distance in m for the smooth start, t in s from 0 to 2."""
    return 0.4 * (t - 2 / np.pi * np.sin(np.pi * t / 2))

def velocity(t):
    """Exact velocity in m/s, the derivative of motion_profile."""
    return 0.4 * (1 - np.cos(np.pi * t / 2))

To compare the smooth start with the start from Chapter 7.1, we compute both velocities at 101 times from 0 to 2 s2\,\text{s}2s. In Chapter 7.1, the velocity increased uniformly at 0.4 m/s20.4\,\text{m/s}^20.4m/s2, so v=0.4 tv = 0.4\,tv=0.4t there. Since velocity() computes with NumPy functions, we can pass it the whole array of times at once.

# velocity in m/s: uniform start from Chapter 7.1, smooth start

The plot compares the two starts.

Both starts reach a velocity of 0.8 m/s0.8\,\text{m/s}0.8m/s after 2 s2\,\text{s}2s. The curve of the smooth start, however, is flat at the beginning and at the end. So the acceleration builds up gradually and tapers off gradually.

For the difference quotients, we write two functions. They take the function they are supposed to differentiate as their first parameter function. In Python, we can pass a function to another function just like a number. We write its name without parentheses, because we pass the function itself and not a function value. In the call forward(motion_profile, 1.5, 0.1), function stands for motion_profile, and function(t + dt) computes motion_profile(1.6).

# difference quotients for any function
def forward(function, t, dt):
    """Forward difference quotient of function at the point t."""
    return (function(t + dt) - function(t)) / dt

def central(function, t, dt):
    """Central difference quotient of function at the point t."""
    return (function(t + dt) - function(t - dt)) / (2 * dt)

We evaluate at t=1.5 st = 1.5\,\text{s}t=1.5s, shortly before the AGV reaches its final velocity, and try three step sizes. As the error, we take the absolute value of the deviation from the exact value.

# point of evaluation in s and exact velocity there
t_0 = 1.5
exact = velocity(t_0)
print(f'Exact velocity at t = {t_0} s: {exact:.6f} m/s')

# error = absolute value of the deviation from the exact value,
# motion_profile without parentheses: we pass the function itself
for dt in [0.1, 0.01, 0.001]:
    error_forward = abs(forward(motion_profile, t_0, dt) - exact)
    error_central = abs(central(motion_profile, t_0, dt) - exact)
    print(f'dt = {dt:5}:  error forward {error_forward:.2e} m/s, '
          f'central {error_central:.2e} m/s')
Exact velocity at t = 1.5 s: 0.682843 m/s
dt =   0.1:  error forward 2.10e-02 m/s, central 1.16e-03 m/s
dt =  0.01:  error forward 2.21e-03 m/s, central 1.16e-05 m/s
dt = 0.001:  error forward 2.22e-04 m/s, central 1.16e-07 m/s

The notation 2.10e-02 stands for 2.10⋅10−22.10 \cdot 10^{-2}2.10⋅10−2. When the step size gets ten times smaller, the error of the forward difference quotient drops to a tenth, and the error of the central difference quotient drops to a hundredth. So the error is roughly proportional to Δt\Delta tΔt and to Δt2\Delta t^2Δt2, respectively. We call the exponent the order of accuracy: the forward difference quotient has order of accuracy 1, the central one has order of accuracy 2. Even at Δt=0.1 s\Delta t = 0.1\,\text{s}Δt=0.1s, the central difference quotient is more accurate than the forward difference quotient at Δt=0.01 s\Delta t = 0.01\,\text{s}Δt=0.01s.

How do we read off the order of accuracy?¶

Three step sizes show the trend, but a plot shows it more clearly. For this, we need many step sizes spanning several powers of ten. np.logspace(-1, -4, 31) generates 31 numbers from 10-1 to 10-4, ten per power of ten. For each step size, we compute both errors in a loop and collect them in arrays that we create beforehand with np.zeros().

# 31 step sizes from 0.1 to 0.0001, ten per power of ten
dt_values = np.logspace(-1, -4, 31)

# errors of both difference quotients for each step size
error_forward = np.zeros(len(dt_values))
error_central = np.zeros(len(dt_values))
for k in range(len(dt_values)):
    error_forward[k] = abs(forward(motion_profile, t_0, dt_values[k]) - exact)
    error_central[k] = abs(central(motion_profile, t_0, dt_values[k]) - exact)

ax.loglog() plots like ax.plot() but uses logarithmic scales on both axes: every power of ten gets the same amount of space on the axis. ax.grid(True, which='both') also draws the fine grid lines between the powers of ten.

In such a log-log plot, the relationship error=C⋅Δtp\text{error} = C \cdot \Delta t^perror=C⋅Δtp becomes a straight line with slope ppp. So the order of accuracy is the slope of the line. We read it off in powers of ten: by how many powers of ten does the error change when the step size changes by one power of ten? We used the same tool for the runtime in the excursus in Chapter 3.7, where the slope was 3.

# plot: error against step size, log-log
fig, ax = plt.subplots(figsize=(7, 5))
ax.loglog(dt_values, error_forward, marker='.', label='forward')
ax.loglog(dt_values, error_central, marker='.', label='central')
ax.set_xlabel('Step size in s')
ax.set_ylabel('Error in m/s')
ax.set_title('Error of the difference quotients at t = 1.5 s')
ax.legend()
ax.grid(True, which='both')
plt.show()

As usual, the step size increases to the right along the axis, so the small step sizes are on the left. Both curves are straight lines. Over three powers of ten of the step size, the error of the forward difference quotient drops by three powers of ten, from about 2⋅10−22 \cdot 10^{-2}2⋅10−2 to about 2⋅10−52 \cdot 10^{-5}2⋅10−5. So the slope is 1. The error of the central difference quotient drops twice as steeply, from about 10-3 to about 10-9, so the slope is 2. Why is the central difference quotient so much more accurate?

Math refresher: Taylor expansion

The Taylor expansion writes a function value near ttt as a sum of powers of the step size:

s(t+Δt)=s(t)+Δt⋅s′(t)+Δt22⋅s′′(t)+Δt36⋅s′′′(t)+…s(t + \Delta t) = s(t) + \Delta t \cdot s'(t) + \frac{\Delta t^2}{2} \cdot s''(t) + \frac{\Delta t^3}{6} \cdot s'''(t) + \ldotss(t+Δt)=s(t)+Δt⋅s′(t)+2Δt2​⋅s′′(t)+6Δt3​⋅s′′′(t)+…

If we substitute this into the forward difference quotient, the largest error term left besides s′(t)s'(t)s′(t) is Δt2⋅s′′(t)\frac{\Delta t}{2} \cdot s''(t)2Δt​⋅s′′(t), which is proportional to Δt\Delta tΔt. In the expansion of s(t−Δt)s(t - \Delta t)s(t−Δt), the odd powers of Δt\Delta tΔt change sign. That is why the terms with s′′(t)s''(t)s′′(t) cancel in the central difference quotient. The largest error term is then Δt26⋅s′′′(t)\frac{\Delta t^2}{6} \cdot s'''(t)6Δt2​⋅s′′′(t), which is proportional to Δt2\Delta t^2Δt2.

For the start, s′′s''s′′ is the acceleration aaa. So the largest error term a⋅Δt/2a \cdot \Delta t / 2a⋅Δt/2 of the forward difference quotient is roughly the change in velocity over half a step. This matches Chapter 7.1: the forward difference quotient gives approximately the velocity at the midpoint of the interval, half a step too late. s′′′s'''s′′′ is the jerk. In Chapter 7.1, the acceleration was constant and the jerk was zero. That is why the central difference quotient was exact there, except at the kink at t=2 st = 2\,\text{s}t=2s. At a kink, the Taylor expansion does not hold, and the central difference quotient can even be worse than the forward difference quotient. At t=2 st = 2\,\text{s}t=2s, the forward difference quotient gives exactly the planned velocity, (1.2−0.8)/0.5=0.8 m/s(1.2 - 0.8)/0.5 = 0.8\,\text{m/s}(1.2−0.8)/0.5=0.8m/s, but the central one only 0.75 m/s0.75\,\text{m/s}0.75m/s. So the orders of accuracy assume that the function can be differentiated often enough, and they describe the error for small step sizes.

What happens with tiny step sizes?¶

According to the Taylor expansion, the error should keep decreasing as the step size gets smaller. We check this and reduce the step size down to 10-15. The calculation is the same as in the previous section, only with 141 step sizes.

# 141 step sizes from 0.1 to 1e-15, ten per power of ten
dt_values = np.logspace(-1, -15, 141)

# errors of both difference quotients for each step size

error_central = np.zeros(len(dt_values))
for k in range(len(dt_values)):
    error_forward[k] = abs(forward(motion_profile, t_0, dt_values[k]) - exact)
    error_central[k] = abs(central(motion_profile, t_0, dt_values[k]) - exact)

We draw the plot as in the previous section, only without markers.

# plot: error down to very small step sizes, log-log
fig, ax = plt.subplots(figsize=(7, 5))

At first, the curves follow the lines from the previous section. They reach their minimum at about 2⋅10−82 \cdot 10^{-8}2⋅10−8 for the forward difference quotient and at about 5⋅10−65 \cdot 10^{-6}5⋅10−6 for the central one. Below that, the error rises again and becomes erratic. At Δt=10−15\Delta t = 10^{-15}Δt=10−15, it is even larger than at Δt=0.1\Delta t = 0.1Δt=0.1. Where does this additional error come from?

Python stores a floating-point number with about 16 significant digits and rounds off the rest. This deviation is called rounding error. We can see what it does in the two function values for Δt=10−10\Delta t = 10^{-10}Δt=10−10. We print them to 17 decimal places with the format :.17f.

# two function values a distance dt = 1e-10 s apart
dt = 1e-10
s_right = motion_profile(t_0 + dt)
s_left = motion_profile(t_0)

# difference and forward difference quotient
difference = s_right - s_left
v_forward = difference / dt

# output with 17 decimal places, exact velocity for comparison
print(f's(t_0 + dt) = {s_right:.17f} m')
print(f's(t_0)      = {s_left:.17f} m')
print(f'difference  = {difference:.17f} m')
print(f'forward     = {v_forward:.17f} m/s')
print(f'exact       = {exact:.17f} m/s')
s(t_0 + dt) = 0.41993673683686306 m
s(t_0)      = 0.41993673676857884 m
difference  = 0.00000000006828421 m
forward     = 0.68284211618419022 m/s
exact       = 0.68284271247461903 m/s

The two function values agree in the first nine decimal places. When we subtract, these digits turn into zeros, and of the roughly 16 significant digits, only about six are left. This loss of significant digits is called cancellation. That is why the difference quotient also agrees with the exact velocity in only six digits.

The machine epsilon eps tells us how accurately Python computes. It is the smallest relative gap between 1 and the next number that Python can store. For quantities around 1, every function value has a rounding error of about eps. Like the measurement noise in Chapter 7.1, the difference quotient divides it by the step size. So the rounding error in the result is about eps/Δt\text{eps} / \Delta teps/Δt, which is why the erratic parts of the curves on the left have a slope of roughly -1.

The best step size is the one at which the error from the Taylor expansion and the rounding error are about the same size. Ignoring the factors CCC, the forward difference quotient gives Δt≈eps/Δt\Delta t \approx \text{eps} / \Delta tΔt≈eps/Δt, which leads to the rule of thumb Δt≈eps\Delta t \approx \sqrt{\text{eps}}Δt≈eps​. For the central one, Δt2≈eps/Δt\Delta t^2 \approx \text{eps} / \Delta tΔt2≈eps/Δt, so Δt≈eps3\Delta t \approx \sqrt[3]{\text{eps}}Δt≈3eps​. NumPy provides eps as np.finfo(float).eps, and we compute the cube root as eps ** (1 / 3).

# machine epsilon
eps = np.finfo(float).eps

# rules of thumb for the best step size
dt_forward = np.sqrt(eps)
dt_central = eps ** (1 / 3)

# output of the rules of thumb
print(f'Machine epsilon eps:          {eps:.1e}')
print(f'forward, square root of eps:  {dt_forward:.1e} s')
print(f'central, cube root of eps:    {dt_central:.1e} s')
Machine epsilon eps:          2.2e-16
forward, square root of eps:  1.5e-08 s
central, cube root of eps:    6.1e-06 s

The rules of thumb 1.5⋅10−81.5 \cdot 10^{-8}1.5⋅10−8 and 6.1⋅10−66.1 \cdot 10^{-6}6.1⋅10−6 match the minima in the plot well. However, they only apply to quantities around 1, like the time around 1.5 s1.5\,\text{s}1.5s and the distance around 0.4 m0.4\,\text{m}0.4m here. If the variable is typically much larger or smaller, the best step size grows or shrinks with it, for the central difference quotient to roughly eps3\sqrt[3]{\text{eps}}3eps​ times the typical size of the variable. The function itself also plays a role. So the rules of thumb only give the order of magnitude.

Summary and outlook¶

If a function is available as a Python function, we pass it to forward() or central() and choose the step size freely. If the function can be differentiated often enough, the forward difference quotient has order of accuracy 1 for small step sizes, and the central difference quotient has order of accuracy 2. In a log-log plot, the order of accuracy appears as the slope, and the Taylor expansion explains it. Very small step sizes do harm because of rounding errors and cancellation, since the rounding error grows like eps/Δt\text{eps} / \Delta teps/Δt. For quantities around 1, step sizes of about eps≈10−8\sqrt{\text{eps}} \approx 10^{-8}eps​≈10−8 for the forward difference quotient and eps3\sqrt[3]{\text{eps}}3eps​, i.e. 10-5 to 10-6, for the central difference quotient work well.

The exercises in Chapter 7.3 review both chapters, including an emergency stop of an AGV. In Chapter 8.1, we search for the parameter of a model that best fits measured data. The derivative shows us the direction, and we compute it with the central difference quotient and the step size 10-6.
