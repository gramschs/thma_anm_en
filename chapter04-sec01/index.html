4.1 From Truss to Stiffness Matrix

In Chapter 3.2 we computed the support reactions of a beam. We set up the three equilibrium conditions by hand. That works well for a beam with two supports. For a crane, a bridge or a roof structure with dozens of members, it quickly becomes hard to keep track. How do we get the computer to set up the system of equations for an entire structure by itself?

For this we consider ideal plane trusses. They consist of straight members that are connected by pins at their ends. The connection points are called nodes. External forces act only at the nodes. Therefore the members are loaded only along their axis, in tension or compression, and not in bending. In this chapter we describe a truss in Python and use it to build the matrix of the system of equations step by step.

Learning objectives¶

Learning objectives

  • You can describe a plane truss in Python using node coordinates, support nodes, a member list and a force vector.

  • You can compute the member stiffness k=EA/Lk = EA/Lk=EA/L and explain why a member transmits forces only in the direction of its axis.

  • You can assemble the stiffness matrix of a truss with a function and explain why it is singular without supports.

How do we describe a truss in Python?¶

Our example is a swing set. The top beam, from which the swings hang, rests at each end on an A-frame made of two inclined steel bars. We look at one of these A-frames from the side. In this view, the swings also move back and forth. The two bars meet at the top in node 1. There the top beam pushes down with 2000 N2000\,\text{N}2000N, which already includes an allowance for the swinging. The two feet, nodes 0 and 2, stand firmly on the ground.

For the calculation we need four pieces of information: Where are the nodes? Which nodes are supported? Which nodes are connected by a member? Which forces act? We translate this directly into Python.

import numpy as np
import matplotlib.pyplot as plt

# node coordinates in m: row n contains [x, y] of node n
node_pos = np.array([
    [0.0, 0.0],   # node 0: left foot
    [1.0, 2.0],   # node 1: apex, the top beam rests here
    [2.0, 0.0],   # node 2: right foot
])
num_nodes = len(node_pos)

# support nodes: these nodes cannot move
support_indices = [0, 2]

# member list: row s contains the numbers of the two nodes of member s
members = np.array([
    [0, 1],   # member 0 connects node 0 and node 1
    [1, 2],   # member 1 connects node 1 and node 2
])

# force vector in N: [F_0x, F_0y, F_1x, F_1y, F_2x, F_2y]
force_vector = np.zeros(2 * num_nodes)
force_vector[3] = -2000.0   # Fy at node 1: 2000 N downward

print('Number of nodes:  ', num_nodes)
print('Number of members:', len(members))
print('Force vector:     ', force_vector)
Number of nodes:   3
Number of members: 2

The node coordinates are stored in a 2D array with one row per node. With node_pos[1] we get the whole row, i.e. both coordinates of node 1. The member list members works the same way: each row is a member and contains the numbers of the two nodes it connects.

We have to look more closely at the force vector. Each node can move in the xxx- and yyy-directions. These two possible movements are called degrees of freedom. Three nodes therefore have six degrees of freedom, and the force vector has six entries. They are ordered node by node: first xxx and yyy of node 0, then of node 1, and so on. In general:

  • index 2n2n2n belongs to the xxx-direction of node nnn,

  • index 2n+12n+12n+1 belongs to the yyy-direction of node nnn.

The load at node 1 in the yyy-direction is therefore at index 2⋅1+1=32 \cdot 1 + 1 = 32⋅1+1=3. The minus sign means that the force points downward, i.e. in the negative yyy-direction.

Before we compute anything, we plot the truss. That way, typos in the coordinates or in the member list stand out immediately. The plotting function is given. We simply run the cell and do not need to understand the code in detail.

def plot_truss(node_pos, members, support_indices, roller_indices=None,
               force_vector=None, displacement=None, scale=1.0,
               member_forces=None, title=''):
    """Plots a plane truss.

    node_pos: node coordinates in m, row n = [x_n, y_n]
    members: member list, row s = [i, j]
    support_indices: list of nodes with a pin support
    roller_indices: list of nodes with a roller support (optional)
    force_vector: external node forces in N, drawn as arrows (optional)
    displacement: displacement vector in m, draws the deformed shape (optional)
    scale: exaggeration factor for the displacements
    member_forces: member forces in N, blue = tension, red = compression, gray = zero force (optional)
    title: plot title
    """
    blue, red, orange, gray = '#005A94', '#E60000', '#E87846', '#484949'
    num_nodes = len(node_pos)
    extent = np.max(np.ptp(node_pos, axis=0))   # larger extent in x or y
    fig, ax = plt.subplots(figsize=(8, 4.5))

    # node positions: initial shape or exaggerated deformed shape
    pos = node_pos.copy()
    if displacement is not None:
        pos = node_pos + scale * displacement.reshape(num_nodes, 2)
        for i, j in members:
            ax.plot(node_pos[[i, j], 0], node_pos[[i, j], 1],
                    color=gray, linestyle='--', linewidth=1)

    # members, colored and labeled if member forces are given
    for s in range(len(members)):
        i, j = members[s]
        color = blue
        if member_forces is not None:
            color = blue if member_forces[s] >= 0 else red
            if abs(member_forces[s]) <= 1e-6 * np.max(np.abs(member_forces)):
                color = '#A6A6A6'   # light gray: member without force (ignore rounding errors)
            mid = 0.5 * (pos[i] + pos[j])
            ax.text(mid[0], mid[1], f' {member_forces[s] / 1000:.2f} kN',
                    color=color, fontsize=9)
        ax.plot(pos[[i, j], 0], pos[[i, j], 1], color=color, linewidth=3)

    # supports as triangles below the nodes, roller supports with an extra line
    if roller_indices is None:
        roller_indices = []
    h = 0.06 * extent
    for n in list(support_indices) + list(roller_indices):
        x, y = node_pos[n]
        ax.fill([x, x - h, x + h], [y, y - 1.5 * h, y - 1.5 * h],
                color='#CCDEE9', edgecolor=gray, zorder=2)
        if n in roller_indices:
            ax.plot([x - h, x + h], [y - 2 * h, y - 2 * h], color=gray, linewidth=2)

    # nodes with numbers
    ax.scatter(pos[:, 0], pos[:, 1], color=orange, s=60, zorder=3)
    for n in range(num_nodes):
        ax.text(pos[n, 0], pos[n, 1], f'  N{n}', color=blue,
                fontsize=10, va='bottom')

    # external forces as arrows pointing at the nodes
    if force_vector is not None:
        forces = force_vector.reshape(num_nodes, 2)
        for n in range(num_nodes):
            magnitude = np.sqrt(forces[n, 0]**2 + forces[n, 1]**2)
            if magnitude > 0:
                direction = forces[n] / magnitude
                start = pos[n] - 0.15 * extent * direction
                ax.annotate('', xy=pos[n], xytext=start,
                            arrowprops=dict(color=gray, width=2, headwidth=8))
                ax.text(start[0], start[1], f' {magnitude:.0f} N', color=gray,
                        fontsize=9)
                ax.plot(start[0], start[1], alpha=0)   # keep the arrow inside the plot area

    if member_forces is not None:
        ax.plot([], [], color=blue, linewidth=3, label='Tension')
        ax.plot([], [], color=red, linewidth=3, label='Compression')
        ax.plot([], [], color='#A6A6A6', linewidth=3, label='Zero force')
        ax.legend(loc='upper right')

    ax.set_title(title)
    ax.set_xlabel('x in m')
    ax.set_ylabel('y in m')
    ax.set_aspect('equal')
    ax.margins(0.15)
    ax.grid(True)

A member acts like a spring¶

So far our truss only describes the geometry and the load. With this information we could even solve the swing set by hand: at each of the three nodes, two equilibrium conditions hold. That gives six equations for six unknowns, namely two member forces and four support reactions. For many trusses, however, this is not enough. If a truss has more members or supports than necessary, there are more unknowns than equilibrium conditions. Such a truss is called statically indeterminate. In addition, we want to know how far the apex sinks under the load. Both become possible once we also take into account how the members deform.

How much a member deforms under load depends on the material. Under tension or compression, a member behaves like a spring. From Hooke’s law σ=E ε\sigma = E\,\varepsilonσ=Eε with the stress σ=F/A\sigma = F/Aσ=F/A and the strain ε=ΔL/L\varepsilon = \Delta L/Lε=ΔL/L it follows that

F=E AL⋅ΔL=k⋅ΔL.F = \frac{E\,A}{L} \cdot \Delta L = k \cdot \Delta L.F=LEA​⋅ΔL=k⋅ΔL.

The member stiffness k=EA/Lk = EA/Lk=EA/L is therefore the spring constant of the member. A thick, short member made of a stiff material is a stiff spring.

Our members are made of steel and have a circular cross-section with a diameter of 1 cm1\,\text{cm}1cm. For the stiffness we still need the member length. We pick out member 0. We compute its length from the coordinates of the two nodes it connects: first the difference vector, then the length with the Pythagorean theorem, L=Δx2+Δy2L = \sqrt{\Delta x^2 + \Delta y^2}L=Δx2+Δy2​.

# material and cross-section, the same for all members
youngs_modulus = 2.1e11                    # steel in N/m²
diameter = 0.01                            # in m
area = np.pi * diameter**2 / 4             # circular area in m²

# member 0: get the node numbers from the member list
i, j = members[0]

# difference vector from node i to node j and member length (Pythagorean theorem)
difference = node_pos[j] - node_pos[i]
length = np.sqrt(difference[0]**2 + difference[1]**2)

# member stiffness k = E * A / L
k = youngs_modulus * area / length

print(f'Member 0 connects nodes {i} and {j}')
print(f'Difference vector: {difference} m')
print(f'Member length:     {length:.4f} m')
print(f'Stiffness k:       {k:.4e} N/m = {k * 1e-6:.2f} kN/mm')

The line i, j = members[0] unpacks the two node numbers into two variables, just as we unpacked the solution into T_AB, T_BC, Q in Chapter 3.3.

Our steel member has k≈7.38 kN/mmk \approx 7.38\,\text{kN/mm}k≈7.38kN/mm: to stretch it by one millimeter, we need a force of about 7.4 kN7.4\,\text{kN}7.4kN.

Unlike a spring lying on a table, our member is inclined in the plane. Nevertheless, it transmits forces only in the direction of its axis. The reason: forces act on the member only at its two ends, because external loads act only at the nodes, and the pins transmit no moment. For the member to be in equilibrium, both forces must be equal in magnitude, opposite in direction and act along the same line; otherwise they would rotate the member. This line is the member axis. We describe its direction with the unit vector e⃗\vec{e}e, the difference vector divided by the member length.

What happens if node 1 moves down by 1 mm1\,\text{mm}1mm? Only the part of the displacement in the direction of the member changes its length; the part perpendicular to it merely rotates the member slightly. The following figure shows this for our member 0, with the displacement greatly exaggerated. Node 0 stays in place, and node 1 moves by u⃗1\vec{u}_1u1​ to the new position 1′1'1′. We split the displacement into the component u∥u^{\parallel}u∥ along the member axis and the component u⊥u^{\perp}u⊥ perpendicular to it. Only u∥u^{\parallel}u∥ changes the member length, so it is exactly the change in length ΔL\Delta LΔL. Here u∥u^{\parallel}u∥ points opposite to e⃗\vec{e}e, so the member gets shorter.

Strictly speaking, u⊥u^{\perp}u⊥ also lengthens the member slightly. This effect, however, grows with the square of the displacement. For displacements of fractions of a millimeter on members more than two meters long, it is negligible. Throughout this chapter we therefore make the small-displacement assumption. It is what makes the relationship between displacements and forces linear.

The force F⃗1\vec{F}_1F1​ in the figure has the subscript 1 because it acts at node 1. For a displacement u⃗1=(ux,uy)⊤\vec{u}_1 = (u_x, u_y)^\topu1​=(ux​,uy​)⊤ of node 1, the dot product with e⃗\vec{e}e gives the component in the direction of the member, i.e. the change in length. The spring equation then gives the force in the direction of the member:

ΔL=ex ux+ey uy,F⃗1=k ΔL e⃗.\Delta L = e_x\,u_x + e_y\,u_y, \qquad \vec{F}_1 = k\,\Delta L\,\vec{e}.ΔL=ex​ux​+ey​uy​,F1​=kΔLe.
# unit vector in the direction of the member axis (length 1)
e = difference / length

# node 1 moves down by 1 mm, node 0 stays in place
displacement_node1 = np.array([0.0, -0.001])   # in m

# change in length: only the component of the displacement along the member counts
delta_l = e[0] * displacement_node1[0] + e[1] * displacement_node1[1]

# external force at node 1 that produces this displacement: magnitude k * delta_l, direction e
force_node1 = k * delta_l * e

print(f'Unit vector e:            {e}')
print(f'Change in length:         {delta_l * 1000:.4f} mm')
print(f'External force at node 1: {force_node1} N')

The member gets shorter by only about 0.89 mm0.89\,\text{mm}0.89mm, not by the full millimeter, because the displacement points straight down, while the member points diagonally upward. The force points along the member, down and to the left: it compresses the member. That is why it also has an xxx-component, even though the node does not move sideways at all. This is the external force needed to displace node 1 in this way. The member exerts a force of equal magnitude in the opposite direction on the node.

We could repeat this calculation for any displacement. It is easier with a 2×22 \times 22×2 matrix that contains the whole relationship at once. To get it, we substitute ΔL\Delta LΔL into F⃗1\vec{F}_1F1​ and write the result as a matrix times a vector:

F⃗1=k (exux+eyuy)(exey)=k(exexexeyeyexeyey)(uxuy).\vec{F}_1 = k\,(e_x u_x + e_y u_y) \begin{pmatrix} e_x \\ e_y \end{pmatrix} = k \begin{pmatrix} e_x e_x & e_x e_y \\ e_y e_x & e_y e_y \end{pmatrix} \begin{pmatrix} u_x \\ u_y \end{pmatrix}.F1​=k(ex​ux​+ey​uy​)(ex​ey​​)=k(ex​ex​ey​ex​​ex​ey​ey​ey​​)(ux​uy​​).

We call this matrix the stiffness block b\mathbf{b}b of the member. With the angle φ\varphiφ from the figure of the member geometry, e⃗=(cos⁡φ,sin⁡φ)⊤\vec{e} = (\cos\varphi, \sin\varphi)^\tope=(cosφ,sinφ)⊤, and the block becomes

b=k(cos⁡2φcos⁡φ sin⁡φcos⁡φ sin⁡φsin⁡2φ).\mathbf{b} = k \begin{pmatrix} \cos^2\varphi & \cos\varphi\,\sin\varphi \\ \cos\varphi\,\sin\varphi & \sin^2\varphi \end{pmatrix}.b=k(cos2φcosφsinφ​cosφsinφsin2φ​).

We never have to compute the angle itself, because the entries of e already are cos⁡φ\cos\varphicosφ and sin⁡φ\sin\varphisinφ. In the code we therefore build the block directly from e and check whether it gives the same force as before.

# stiffness block of the member: converts a displacement into a force
block = k * np.array([
    [e[0] * e[0], e[0] * e[1]],
    [e[1] * e[0], e[1] * e[1]],
])

print('Stiffness block in kN/mm:')

From members to the stiffness matrix¶

Each member gives a stiffness block. Now we combine all blocks into one large matrix that describes the whole truss, the stiffness matrix K\mathbf{K}K. It has one row and one column for each degree of freedom, so 6×66 \times 66×6 entries for the swing set. It relates the displacements of all nodes to the forces at all nodes:

K⋅u⃗=F⃗.\mathbf{K} \cdot \vec{u} = \vec{F}.K⋅u=F.

The displacement vector u⃗\vec{u}u is ordered in the same way as the force vector: index 2n2n2n belongs to the xxx-displacement of node nnn, index 2n+12n+12n+1 to the yyy-displacement.

So far node 0 stayed in place, and only node 1 moved. In a truss, both end nodes iii and jjj of a member can move. The force in the member, however, depends only on how far the two end nodes move relative to each other. If both move the same distance in the same direction, the member length stays the same, and no force is produced. For the forces at nodes iii and jjj we therefore have

F⃗i=b (u⃗i−u⃗j),F⃗j=b (u⃗j−u⃗i).\vec{F}_i = \mathbf{b}\,(\vec{u}_i - \vec{u}_j), \qquad \vec{F}_j = \mathbf{b}\,(\vec{u}_j - \vec{u}_i).Fi​=b(ui​−uj​),Fj​=b(uj​−ui​).

If node iii does not move, i.e. u⃗i=0⃗\vec{u}_i = \vec{0}ui​=0, this reduces to F⃗j=b u⃗j\vec{F}_j = \mathbf{b}\,\vec{u}_jFj​=buj​. That is exactly our calculation for member 0 from the last section. If we expand the parentheses, we see where the block ends up in K\mathbf{K}K:

(F⃗iF⃗j)=(b−b−bb)(u⃗iu⃗j).\begin{pmatrix} \vec{F}_i \\ \vec{F}_j \end{pmatrix} = \begin{pmatrix} \mathbf{b} & -\mathbf{b} \\ -\mathbf{b} & \mathbf{b} \end{pmatrix} \begin{pmatrix} \vec{u}_i \\ \vec{u}_j \end{pmatrix}.(Fi​Fj​​)=(b−b​−bb​)(ui​uj​​).

Each member therefore adds +b+\mathbf{b}+b to the two diagonal blocks (i,i)(i, i)(i,i) and (j,j)(j, j)(j,j) and −b-\mathbf{b}−b to the two off-diagonal blocks (i,j)(i, j)(i,j) and (j,i)(j, i)(j,i).

To add the blocks, we need a new tool, slicing. The expression K[0:2, 2:4] selects rows 0 and 1 and columns 2 and 3, i.e. a 2×22 \times 22×2 block. As with range, the upper bound is not included. Member 0 connects node 0 to node 1. Node 0 occupies rows and columns 0 and 1, node 1 rows and columns 2 and 3. We first add the block of member 0 by hand.

# empty matrix: one row and one column per degree of freedom
K_member0 = np.zeros((2 * num_nodes, 2 * num_nodes))

# member 0 connects node 0 (rows/columns 0:2) to node 1 (rows/columns 2:4)
K_member0[0:2, 0:2] += block   # diagonal block (0, 0)
K_member0[2:4, 2:4] += block   # diagonal block (1, 1)
K_member0[0:2, 2:4] -= block   # off-diagonal block (0, 1)
K_member0[2:4, 0:2] -= block   # off-diagonal block (1, 0)

print('Contribution of member 0 in kN/mm:')

Member 0 fills only the rows and columns of node 0 and node 1. Node 2 is not attached to member 0, so its rows and columns remain zero. For member 1 we would have to repeat the same with node 1 and node 2, i.e. with the ranges 2:4 and 4:6. For a truss with dozens of members this would be very tedious. We therefore replace the fixed bounds: node nnn occupies rows and columns 2n2n2n and 2n+12n+12n+1, i.e. the range 2*n : 2*n + 2. With this we add all members in a loop over the member list. Since we need this for every truss, we write a function right away. In the loop we compute exactly what we did by hand for member 0.

def assemble_stiffness_matrix(node_pos, members, youngs_modulus, area):
    """Assembles the stiffness matrix of a plane truss.

    node_pos: node coordinates in m, row n = [x_n, y_n]
    members: member list, row s = [i, j]
    youngs_modulus: E in N/m², the same for all members
    area: A in m², the same for all members
    Returns: stiffness matrix K in N/m, shape (2 * number of nodes, 2 * number of nodes)
    """
    num_dofs = 2 * len(node_pos)
    K = np.zeros((num_dofs, num_dofs))

    for i, j in members:
        # geometry and stiffness of the member
        difference = node_pos[j] - node_pos[i]
        length = np.sqrt(difference[0]**2 + difference[1]**2)
        k = youngs_modulus * area / length
        e = difference / length

        # stiffness block of the member
        block = k * np.array([
            [e[0] * e[0], e[0] * e[1]],
            [e[1] * e[0], e[1] * e[1]],
        ])

        # add the block to K: +block at i-i and j-j, -block at i-j and j-i
        K[2*i : 2*i + 2, 2*i : 2*i + 2] += block
        K[2*j : 2*j + 2, 2*j : 2*j + 2] += block
        K[2*i : 2*i + 2, 2*j : 2*j + 2] -= block
        K[2*j : 2*j + 2, 2*i : 2*i + 2] -= block

    return K

K = assemble_stiffness_matrix(node_pos, members, youngs_modulus, area)

In the block of node 1, the contributions of both members add up. That is why the function uses += and not =: with =, member 1 would overwrite the contribution of member 0. The off-diagonal entries cancel because the two members are mirror images of each other. The block K[0:2, 4:6] links the degrees of freedom of node 0 with those of node 2. In the swing set there is no member between these nodes, so the function adds nothing there. Only member 0 is attached to node 0, so its diagonal block contains only the stiffness block of member 0.

With the new member, K_new[0:2, 4:6] is no longer zero. The member is horizontal and 2 m2\,\text{m}2m long, and its stiffness is k=8.25 kN/mmk = 8.25\,\text{kN/mm}k=8.25kN/mm. The block therefore contains only one entry, in the top left, namely −8.25 kN/mm-8.25\,\text{kN/mm}−8.25kN/mm. The minus sign comes from the off-diagonal block.

K_new is also singular; the determinant is zero. The new member only prevents node 0 and node 2 from moving relative to each other. We can still shift the whole triangle to the right without any member length changing, exactly as above with u_rigid. So the matrix is singular because of the missing supports, not because of a missing member.

Summary and outlook¶

We describe a plane truss with four data structures: the node coordinates, the support nodes, the member list and the force vector. Each node has two degrees of freedom; node nnn occupies the indices 2n2n2n and 2n+12n+12n+1. Each member acts like a spring with the stiffness k=EA/Lk = EA/Lk=EA/L and gives a 2×22 \times 22×2 stiffness block. The function assemble_stiffness_matrix uses slicing to add each block to the stiffness matrix K\mathbf{K}K, positive on the diagonal blocks and negative on the off-diagonal blocks. Without supports, K\mathbf{K}K is singular, because the truss can move without any force arising.

In the next chapter, working in pairs, we apply the function to a larger truss, a wall bracket for a pipe. In Chapter 4.3 we then add the supports, solve the system of equations and compute how far the apex of the swing set sinks and whether it can carry the load.
