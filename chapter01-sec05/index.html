1.5 Exercises

These exercises are intended for self-study at home and review the material of chapters 1.1 to 1.4. Expect around two hours of working time.

The difficulty level is given in the title of each exercise:

  • ✩ Comprehension: predict and explain code and outputs (approx. 5 min)

  • ✩✩ Application: write your own code and interpret results (approx. 10 min)

  • ✩✩✩ Mini-project: combine several concepts from this chapter (approx. 30 min)

Exercise 1.1 (✩)

Which data type is present? Write your guess after the arrow before you run the code.

  • 7 -->

  • -7 -->

  • 'steel' -->

  • 7.0 -->

  • 7,0 -->

  • 7**2 -->

  • 7**(1/2) -->

  • 7 == 7.0 -->

Then check each line with type() in a code cell.

# code cell
Solution
print(type(7))
print(type(-7))
print(type('steel'))
print(type(7.0))

comma_number = 7,0
print(type(comma_number))

print(type(7**2))
print(type(7**(1/2)))
print(type(7 == 7.0))

7 and -7 are integers, 'steel' is a string, 7.0 is a float. 7**2 stays an integer (49), 7**(1/2) is a float (2.6457513110645907). 7 == 7.0 is a bool with the value True, because Python looks at the numeric value in a comparison, not the data type.

The most interesting case is 7,0: in Python the comma does not create a decimal number but a tuple (7, 0), so type(comma_number) returns tuple. No error occurs in the process, which makes this typo particularly treacherous. For decimal numbers, therefore, always use a point instead of a comma.

Exercise 1.2 (✩✩)

A spring obeys the spring law force = spring_constant * displacement. Compute the spring force for a spring constant of 250 N/m and a displacement of 0.12 m. Print the result with an f-string and the unit newton, rounded to two decimal places.

# code cell
Solution
spring_constant = 250   # N/m
displacement = 0.12     # m

force = spring_constant * displacement
print(f'Spring force: {force:.2f} N')

The spring force is 30.00 N. Since spring_constant is an integer and displacement is a float, Python automatically converts the result of the multiplication to a float.

Exercise 1.3 (✩)

What do the following expressions return? Note True or False before you run the code.

  • 5 > 3 -->

  • 5 >= 5 -->

  • 'Steel' == 'steel' -->

  • not (5 > 3) -->

  • (5 > 3) and (2 > 4) -->

  • (5 > 3) or (2 > 4) -->

# code cell
Solution
print(5 > 3)
print(5 >= 5)
print('Steel' == 'steel')
print(not (5 > 3))
print((5 > 3) and (2 > 4))
print((5 > 3) or (2 > 4))

5 > 3 and 5 >= 5 are True. 'Steel' == 'steel' is False, because Python distinguishes uppercase and lowercase when comparing strings. not (5 > 3) inverts True to False. With and both sides must be true, so the result is False. With or one true side is enough, so the result is True.

Exercise 1.4 (✩✩)

A material has a measured tensile strength of tensile_strength_mpa = 420. Write an if/elif/else branch that prints the following categories:

  • below 300 MPa: 'low-strength'

  • from 300 to 600 MPa (both inclusive): 'medium-strength'

  • above 600 MPa: 'high-strength'

# code cell
Solution
tensile_strength_mpa = 420

if tensile_strength_mpa < 300:
    category = 'low-strength'
elif tensile_strength_mpa <= 600:
    category = 'medium-strength'
else:
    category = 'high-strength'

print(f'Category: {category}')

At 420 MPa the material lies in the range from 300 to 600 MPa and is therefore classified as 'medium-strength'.

Exercise 1.5 (✩✩)

Write a for loop that prints the value in Fahrenheit for the temperatures 0, 20, 40, 60, 80 and 100 degrees Celsius. Use the formula fahrenheit = celsius * 9/5 + 32 for this.

Hint: range(start, stop, step) generates numbers with a step size other than 1. The value stop itself no longer belongs to the range, so choose it suitably larger.

# code cell
Solution
for celsius in range(0, 101, 20):
    fahrenheit = celsius * 9/5 + 32
    print(f'{celsius} degrees Celsius corresponds to {fahrenheit:.1f} degrees Fahrenheit')

range(0, 101, 20) generates the values 0, 20, 40, 60, 80 and 100. Since the value 101 itself is no longer contained in the range, this choice covers all six desired temperatures.

Exercise 1.6 (✩✩)

A component cools down from 180 degrees Celsius by 12 degrees in each time step. Write a for loop with range(15) that computes and prints the temperature for each time step. Add an if check in the loop body that additionally prints below 20 degrees as soon as the temperature falls below the mark of 20 degrees Celsius.

# code cell
Solution
for time_step in range(15):
    temperature = 180 - time_step * 12
    print(f'Time step {time_step}: {temperature} degrees Celsius')
    if temperature < 20:
        print('below 20 degrees')

The temperature drops in uniform steps from 180 to 12 degrees Celsius. At time step 14 it is 12 degrees Celsius, below the 20-degree mark for the first time; the additional message appears there. With range(15) we cover all time steps up to the point where the temperature drops below the mark.

Exercise 1.7 (✩)

The list my_list = [15, 8, 23, 4, 16, 42] is given. Note down your guess first, before you run the code.

  • my_list[0] -->

  • my_list[2] -->

  • my_list[-1] -->

  • my_list[-3] -->

  • len(my_list) -->

# code cell
Solution
my_list = [15, 8, 23, 4, 16, 42]
print(my_list[0])
print(my_list[2])
print(my_list[-1])
print(my_list[-3])
print(len(my_list))

my_list[0] is 15, the first element, my_list[2] is 23, the element at index 2. my_list[-1] is 42, the last element. my_list[-3] is 4, because counting from the back, 42 is at -1, 16 at -2 and 4 at -3. len(my_list) yields 6, the number of elements.

Exercise 1.8 (✩✩)

The list measurement_series = [15.2, 8.7, 23.1, 4.4, 16.9, 42.0] with force readings in newtons is given. Determine the smallest and largest value of the list with a for loop, without using the built-in functions min() and max().

# code cell
Solution
measurement_series = [15.2, 8.7, 23.1, 4.4, 16.9, 42.0]

minimum = measurement_series[0]
maximum = measurement_series[0]

for value in measurement_series:
    if value < minimum:
        minimum = value
    if value > maximum:
        maximum = value

print(f'Minimum: {minimum} N, maximum: {maximum} N')

We start minimum and maximum with the first list element and then compare every further element. The minimum of the measurement series is 4.4 N, the maximum is 42.0 N.

Exercise 1.9 (✩✩)

Create a dictionary part for a shaft with the following information:

  • designation: 'Shaft_A1'

  • diameter_mm: 25.0

  • material: '42CrMo4'

  • max_torque_nm: 180

Then print: “Shaft_A1 made of 42CrMo4 (diameter 25.0 mm) withstands a maximum of 180 Nm.”

# code cell
Solution
part = {
    'designation': 'Shaft_A1',
    'diameter_mm': 25.0,
    'material': '42CrMo4',
    'max_torque_nm': 180
}

print(f'{part["designation"]} made of {part["material"]} '
      f'(diameter {part["diameter_mm"]} mm) withstands a maximum of '
      f'{part["max_torque_nm"]} Nm.')

Each value is accessed via the matching key. Here, a dictionary immediately shows which value stands for what, in contrast to a list with the same four values.

Exercise 1.10 (✩✩)

Write a function stress(force_n, cross_section_mm2=100) that computes and returns the mechanical stress sigma = force_n / cross_section_mm2 in N/mm² (MPa). Give the function a docstring. Call the function once with force_n = 5000 and the default cross section, and once with force_n = 5000 and cross_section_mm2 = 50. Compare the two results in one sentence.

# code cell
Solution
def stress(force_n, cross_section_mm2=100):
    """Computes the mechanical stress in MPa (N/mm²)."""
    return force_n / cross_section_mm2

print(f'{stress(5000):.1f} MPa')
print(f'{stress(5000, cross_section_mm2=50):.1f} MPa')

With the default cross section of 100 mm² the stress is 50.0 MPa, with the smaller cross section of 50 mm² the stress doubles to 100.0 MPa. The same force is distributed over less area with a smaller cross section, which increases the stress.

Exercise 1.11 (✩✩✩, mini-project)

In a tensile test, a sample with the constant cross section cross_section_mm2 = 19.6 is loaded step by step. The measured forces are forces_n = [1200, 3400, 5800, 7200, 8100, 6500]. Implement the following steps.

Part 1: Write a function stress(force_n, cross_section_mm2) that returns the stress in MPa.

Part 2: Create a dictionary test with the keys material ('S235JR'), cross_section_mm2 (19.6) and yield_strength_mpa (235.0).

Part 3: Iterate over forces_n with a for loop. Compute the stress for each value with your function and print for each measured value whether the yield strength from the dictionary is exceeded ('In the elastic range' or 'Yield strength exceeded'). Also keep track of the force at which the yield strength is first exceeded.

Part 4: Determine the maximum stress of the entire measurement series without max() and print it at the end.

Closing question: At which force from the list is the yield strength first exceeded, and what does that mean physically for the material sample?

# code cell
Solution
def stress(force_n, cross_section_mm2):
    """Computes the mechanical stress in MPa (N/mm²)."""
    return force_n / cross_section_mm2

test = {
    'material': 'S235JR',
    'cross_section_mm2': 19.6,
    'yield_strength_mpa': 235.0
}

forces_n = [1200, 3400, 5800, 7200, 8100, 6500]

max_stress = 0
first_exceedance_force = 0
exceedance_found = False

for force in forces_n:
    sigma = stress(force, test['cross_section_mm2'])

    if sigma > test['yield_strength_mpa']:
        status = 'Yield strength exceeded'
        if not exceedance_found:
            first_exceedance_force = force
            exceedance_found = True
    else:
        status = 'In the elastic range'

    print(f'{force} N -> {sigma:.1f} MPa: {status}')

    if sigma > max_stress:
        max_stress = sigma

print(f'Maximum stress: {max_stress:.1f} MPa')
print(f'First exceedance at {first_exceedance_force} N')

The yield strength of 235.0 MPa is first exceeded at 5800 N, where the stress is about 295.9 MPa. The maximum stress of the entire measurement series occurs at the largest force of 8100 N and is about 413.3 MPa, because with a constant cross section the stress grows proportionally to the force.

Physically, exceeding the yield strength means that from this loading point onward the material sample no longer deforms purely elastically, but plastically. The sample thus takes on a permanent deformation that does not disappear even after complete unloading.
