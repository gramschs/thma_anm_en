1.1 Variables, Operators and Control Structures

In vehicle development, sensors continuously deliver measured values: the speed of a test vehicle, the force on a test rig or the temperature of a component. Before we analyze such measurement series with numerical methods in the following chapters, we need the tools of the Python programming language. In this chapter we learn how to store individual measured values in variables, compute with them and control the flow of our program with branches and loops.

We work with Jupyter notebooks. A notebook consists of individual code cells that we run one after another. The result of a cell appears directly below it, so that we can build up and test our code step by step. Let us try this right away with a first example.

If you have never programmed before, you can watch the short videos as preparation; they are embedded at the end of each section in this chapter.

Learning objectives¶

Learning objectives

  • You know the data types integer, float and string and can tell them apart with type().

  • You can create variables, print them with the print() function and format them with f-strings.

  • You know arithmetic, comparison and logical operators and the difference between assignment = and comparison ==.

  • You can branch a program flow with if/elif/else.

  • You can write a for loop with range().

How do we store measured values in variables?¶

Imagine a sensor on a test vehicle measures the current speed. We want to store this value along with further information about the measurement in our program.

speed = 27.8
num_measurements = 50
sensor_name = 'Sensor_A'

We call speed, num_measurements and sensor_name variables. A variable is like a labeled drawer: we give it a name and put a value inside. Putting a value inside is called assignment, and we use the equals sign = for it. Technically, the drawer is a small area in the computer’s memory.

Next we print the content of the variables to the monitor or display. For this we use Python’s built-in print() function.

print(speed)
print(num_measurements)
print(sensor_name)
27.8
50
Sensor_A

We recognize functions by the parentheses after the function name. Into these parentheses goes the so-called argument. An argument is, so to speak, the input passed to the function so that Python knows which value to display on the screen.

Python distinguishes the values in a variable by their data type. In this section we introduce three simple data types:

  • Integer: a whole number, for example the number of measurements.

  • Float: a decimal number, for example a speed in km/h. The decimal separator in Python is always a point, never a comma.

  • String: a sequence of characters, for example the name of a sensor. Strings are enclosed in single or double quotation marks.

With the type() function we display the data type of a variable.

print(type(speed))
print(type(num_measurements))
print(type(sensor_name))
<class 'float'>
<class 'int'>
<class 'str'>

Variables can also be changed later. We often write code like the following example to increase a variable by a value.

num_measurements = num_measurements + 1
print(num_measurements)
51

Doesn’t that contradict mathematics? In mathematics we would be allowed to subtract num_measurements from both sides of the equation and would arrive at 0 = 1, which is obviously false. In Python, however, the equals sign = is not a mathematical equation but an assignment. Python first computes the value on the right-hand side and then stores the result in the variable on the left-hand side.

To print values together with text, we use f-strings. For this we put an f directly in front of the quotation mark and write the variable name in curly braces.

print(f'The sensor {sensor_name} measures a speed of {speed} km/h.')
The sensor Sensor_A measures a speed of 27.8 km/h.

For floats we can additionally specify the number of decimal places. For this we write a colon after the variable name, followed by the desired number of decimal places and an f.

pi = 3.141592653589793
print(f'Pi to two decimal places: {pi:.2f}')
Pi to two decimal places: 3.14

How do we compute and compare in Python?¶

From the introductory physics lecture we already know the SI unit m/s for speed. Sensor data, however, is often given in km/h, so we first convert.

speed_kmh = 100
speed_ms = speed_kmh / 3.6
print(speed_ms)
27.77777777777778

Python knows the usual arithmetic operators: + for addition, - for subtraction, * for multiplication, / for division and ** for exponentiation. With these operators we compute, for example, the kinetic energy of a vehicle.

mass = 1200        # kg
speed_ms = 27.8    # m/s

kinetic_energy = 0.5 * mass * speed_ms**2
print(f'Kinetic energy: {kinetic_energy:.1f} joules')
Kinetic energy: 463704.0 joules

Besides computing with numbers, we often need to compare values as well, for example to check whether a speed limit is being observed. For this we have comparison operators: >, <, >=, <=, == for “is equal to” and != for “is not equal to”. The result of a comparison is always a truth value, that is, either True or False.

speed_limit_ms = 33.3   # corresponds to 120 km/h

print(speed_ms > speed_limit_ms)
print(speed_ms == speed_limit_ms)
False
False
Caution: = is not the same as ==

The single equals sign = is the assignment operator and stores a value in a variable. The double equals sign == compares two values and returns True or False. This mix-up is one of the most common beginner mistakes in Python.

We combine several conditions with the logical operators and and or. With and both conditions must be true, with or one is enough.

is_fast = speed_ms > 25
is_within_limit = speed_ms <= speed_limit_ms

print(is_fast and is_within_limit)
True

With the not operator we invert a truth value: True becomes False and vice versa.

How does our program control the flow?¶

So far, every line of our program was executed exactly once. Often, however, we want to run different code depending on a condition, for example depending on whether a speed limit is being observed.

speed_ms = 35.0
speed_limit_ms = 33.3

if speed_ms > speed_limit_ms:
    print('Speed too high!')
elif speed_ms == speed_limit_ms:
    print('Speed exactly at the limit.')
else:
    print('Speed within the permitted range.')
Speed too high!

We call this structure a branch. The line with if is called the header and is terminated with a colon :. All statements that belong to this condition are indented by the same number of spaces. This indentation shows Python which code belongs together. With elif (short for “else if”) we check a further condition, with else we catch all remaining cases.

Often we need to repeat a statement several times, for example to simulate several time steps of a measurement. For this we use the for loop together with the range() function.

for time_step in range(5):
    print(f'Time step {time_step}: measurement is being carried out.')
Time step 0: measurement is being carried out.
Time step 1: measurement is being carried out.
Time step 2: measurement is being carried out.
Time step 3: measurement is being carried out.
Time step 4: measurement is being carried out.

The header consists of the fixed keywords for and in. Between them is time_step, the loop variable. On each pass it takes the next value from range(5), that is, 0, 1, 2, 3 and 4 in turn, because range(5) generates five numbers starting at 0. The indented lines below form the loop body and are executed on each pass.

Within the loop body we may also use a branch, for example to check for each time step whether a limit value is exceeded.

for time_step in range(5):
    speed_ms = time_step * 12.0
    if speed_ms > speed_limit_ms:
        print(f'Time step {time_step}: {speed_ms:.1f} m/s, too fast!')
    else:
        print(f'Time step {time_step}: {speed_ms:.1f} m/s, within the limit.')
Time step 0: 0.0 m/s, within the limit.
Time step 1: 12.0 m/s, within the limit.
Time step 2: 24.0 m/s, within the limit.
Time step 3: 36.0 m/s, too fast!
Time step 4: 48.0 m/s, too fast!

The loop runs through all five time steps. On each pass we compute the current speed and decide with the if check which message is printed.

Mini-exercise (✩)

Write a for loop with range(5) that, starting from 0 km/h, increases the speed by 30 km/h on each pass of the loop and prints the respective value.

Add an if check in the loop body that additionally prints too fast as soon as the speed exceeds 80 km/h. Answer before running: in which passes does too fast appear? Justify your answer.

# code cell
Solution
for time_step in range(5):
    speed_kmh = time_step * 30
    print(f'Time step {time_step}: {speed_kmh} km/h')
    if speed_kmh > 80:
        print('too fast')

The loop variable time_step runs through the values 0 to 4, the speed takes the values 0, 30, 60, 90 and 120 km/h. too fast appears in passes 3 and 4, because there the speed is 90 and 120 km/h respectively, above the limit of 80 km/h.

Summary and outlook¶

In this chapter we covered the basic building blocks of Python: variables for storing measured values, the data types integer, float and string, arithmetic, comparison and logical operators, as well as branching with if/elif/else and the for loop for repetition. With these we can already process individual values and automate recurring calculations.

What we still lack, however, is a way to manage several measured values together. In the next chapter, 1.2, we deepen what we have learned with test-rig tasks. In chapter 1.3 we then introduce the data structures list and dictionary and write our own functions to encapsulate recurring calculations such as the conversion from km/h to m/s. In chapter 2 we finally use NumPy and Matplotlib to process and plot entire measurement series without loops.
