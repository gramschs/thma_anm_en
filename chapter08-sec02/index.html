8.2 Cooling Constant from Measured Data

In Chapter 8.1, operations management gave us a ready-made cost function. Now you set up a cost function yourself. It measures how well a model fits measured data, and gradient descent searches for the parameter for which the model and the measurements agree best. Work through the parts in pairs if possible, and in order.

Project: When can the part be packed? (✩✩)

A company washes aluminum parts and then dries them in an oven at 100 °C100\,°\text{C}100°C. The parts then cool on a fan-cooled conveyor belt in the factory, where the air temperature is 20 °C20\,°\text{C}20°C. They must not be wrapped in plastic film until they are below 40 °C40\,°\text{C}40°C, or condensation will form inside the packaging. A thermocouple recorded the temperature of one part every 5 s5\,\text{s}5s.

For the temperature TTT at time ttt, we use Newton’s law of cooling:

T(t)=T∞+(T0−T∞)⋅e−λt.T(t) = T_\infty + (T_0 - T_\infty) \cdot e^{-\lambda t}.T(t)=T∞​+(T0​−T∞​)⋅e−λt.

We are looking for the cooling constant λ\lambdaλ and the time the part has to stay on the belt.

First run the following cell. It contains the functions central() and gradient_descent() from Chapter 8.1, the known temperatures and the measured data.

import numpy as np
import matplotlib.pyplot as plt

# functions from Chapter 8.1
def central(function, point, dx):
    """Central difference quotient of function at the given point."""
    return (function(point + dx) - function(point - dx)) / (2 * dx)

def gradient_descent(function, start, learning_rate, tolerance,
                     max_iterations):
    """Search for a minimum of function, starting at start.

    Returns all visited points as an array.
    """
    point = start
    history = [point]
    for k in range(max_iterations):
        slope = central(function, point, 1e-6)
        # stopping criterion: slope almost zero
        if abs(slope) < tolerance:
            break
        point = point - learning_rate * slope
        history.append(point)
    return np.array(history)

# known temperatures in °C
T_start = 100.0
T_ambient = 20.0

# measurement times in s and measured temperatures in °C
t_meas = np.array([0, 5, 10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60])
T_meas = np.array([100.0, 82.6, 68.2, 56.9, 49.0, 41.9, 37.9, 35.2, 30.3,
                   27.8, 27.1, 25.5, 24.1])

Part 2: Cost function from the measured data

To measure how well a value of λ\lambdaλ fits, we look at the deviations between the measurements and the model. We square each deviation and take the mean over all nnn measurements. This gives the mean squared error (MSE):

C(λ)=1n∑i=1n(Tmeas,i−T(ti))2.C(\lambda) = \frac{1}{n} \sum_{i=1}^{n} \bigl(T_{\text{meas},i} - T(t_i)\bigr)^2.C(λ)=n1​i=1∑n​(Tmeas,i​−T(ti​))2.

Because we square the deviations, positive and negative deviations do not cancel each other out, and large deviations count more than small ones.

Unlike total_cost() in Chapter 8.1, cost() only accepts a single number λ\lambdaλ, because the function already works with the array t_meas internally. So you compute the 300 values in a loop.

Closing question

  1. The conveyor belt moves at 0.05 m/s0.05\,\text{m/s}0.05m/s. What is the minimum length of the cooling section?

  2. The smallest value of the cost function is not zero, but C=0.36 °C2C = 0.36\,°\text{C}^2C=0.36°C2. Why does gradient descent not find a λ\lambdaλ for which CCC is zero? What does the square root of this value tell us about the fit?

Solution closing question

  1. In 27.5 s27.5\,\text{s}27.5s at 0.05 m/s0.05\,\text{m/s}0.05m/s, the part travels 0.05 m/s⋅27.5 s≈1.38 m0.05\,\text{m/s} \cdot 27.5\,\text{s} \approx 1.38\,\text{m}0.05m/s⋅27.5s≈1.38m. Allowing for some margin, the cooling section should be at least 1.5 m1.5\,\text{m}1.5m long.

  2. CCC would only be zero if the model curve passed exactly through all 13 data points. There are two reasons why it does not. First, the thermocouple does not measure exactly, and measurement noise pushes each reading a little up or down. Second, the law of cooling is a simplification. For example, it assumes that the part has the same temperature throughout and that the fan cools it evenly. A smooth curve with a single free parameter can follow neither the noise nor every detail of the real cooling process.

    The square root of the mean squared error is in °C°\text{C}°C again. Here it is 0.36 °C2=0.6 °C\sqrt{0.36\,°\text{C}^2} = 0.6\,°\text{C}0.36°C2​=0.6°C. So a typical measurement lies about 0.6 °C0.6\,°\text{C}0.6°C off the model curve. This is accurate enough for designing the cooling section. The value alone does not tell us how much of it is measurement noise and how much is model error. Only the deviations of the individual measurements from the curve reveal that. If they scatter up and down without a pattern, noise dominates. If they stay on the same side of the curve over longer stretches, the model does not describe the process accurately.
